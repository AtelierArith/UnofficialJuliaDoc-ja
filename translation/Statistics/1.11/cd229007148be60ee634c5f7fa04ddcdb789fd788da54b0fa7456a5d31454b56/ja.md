```julia
quantile(f, v)
```

コレクション `v` の各要素に関数 `f` を適用し、区間 [0,1] 内の指定された確率、確率のベクトル、または確率のタプル `p` における分位点を計算します。

```jldoctest
julia> using Statistics

julia> quantile(√, [1, 3, 2], 0.3)
1.248528137423857

julia> quantile([√1, √3, √2], 0.3)
1.248528137423857

julia> quantile(√, [1, 3, 2], (0.3, 0.4, 0.5))
(1.248528137423857, 1.3313708498984762, 1.4142135623730951)

julia> quantile(.√[1, 3, 2], (0.3, 0.4, 0.5))
(1.248528137423857, 1.3313708498984762, 1.4142135623730951)
```
