# macOS

最新の Xcode コマンドラインツールをインストールしておく必要があります。ターミナルで `xcode-select --install` を実行してください。macOS をアップデートするたびに、このターミナルコマンドを再度実行する必要があります。実行しないと、ライブラリやヘッダーが見つからないことによるエラーが発生する場合があります。

依存ライブラリは [BinaryBuilder](https://binarybuilder.org) を使ってビルドされるようになり、自動的にダウンロードされます。Julia のソースをビルドするには、この方法が推奨されます。依存ライブラリをすべて自分でビルドする場合は、Julia の依存関係をコンパイルするために 64 ビット版の gfortran が必要です。

```bash
brew install gcc
```

`LD_LIBRARY_PATH` または `DYLD_LIBRARY_PATH` を `.bashrc` などに設定していると、Julia が同梱ライブラリを見つけられない場合があります。Julia を動作させるには、これらの環境変数を設定解除する必要があります。
