# Calling Conventions

Juliaでは、4つの異なる目的に応じて、3種類の呼び出し規約を使用します。

| 名前      | プレフィックス   | 目的              |
|:------- |:--------- |:--------------- |
| Native  | `julia_`  | 特化したシグネチャによる高速化 |
| JL Call | `jlcall_` | 汎用呼び出し用のラッパー    |
| JL Call | `jl_`     | 組み込み関数          |
| C ABI   | `jlcapi_` | Cから呼び出せるラッパー    |

## Julia Native Calling Convention

ネイティブ呼び出し規約は、ジェネリックではない呼び出しを高速に行うために設計されています。通常、特化したシグネチャを使用します。

  * LLVMのゴースト（長さゼロの型）は省略されます。
  * LLVMのスカラーとベクトルは値渡しされます。
  * LLVMの集成体（配列と構造体）は参照渡しされます。

小さな戻り値はLLVMの戻り値として返されます。大きな戻り値は「構造体戻り値」（`sret`）規約で返されます。この場合、呼び出し元が戻り値用スロットへのポインターを渡します。

引数または戻り値が同種のタプルの場合、LLVM配列ではなくLLVMベクトルとして表現されることがあります。

## JL Call Convention

JL Call規約は、組み込み関数とジェネリックディスパッチに使用されます。この規約を使う手書きの関数は、マクロ`JL_CALLABLE`で宣言します。この規約では、パラメーターを正確に3つ使用します。

  * `F`  - 適用される関数のJulia表現
  * `args` - ボックスへのポインターを格納した配列へのポインター
  * `nargs` - 配列の長さ

戻り値はボックスへのポインターです。

## C ABI

C ABIラッパーを使うと、CからJuliaを呼び出せます。このラッパーは、ネイティブ呼び出し規約を使って関数を呼び出します。

タプルは常にC配列として表現されます。
