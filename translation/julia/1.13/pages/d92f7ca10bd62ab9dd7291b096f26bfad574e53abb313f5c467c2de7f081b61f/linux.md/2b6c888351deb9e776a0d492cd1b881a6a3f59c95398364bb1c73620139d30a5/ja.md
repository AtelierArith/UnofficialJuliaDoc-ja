# Linux

  * Julia のビルドには GCC 4.7 以降が必要です。
  * システムのライブラリ検索パスにない外部共有ライブラリを使用するには、`Make.user` で `USE_SYSTEM_XXX=1` と `LDFLAGS=-Wl,-rpath,/path/to/dir/contains/libXXX.so` を設定します。
  * `LDFLAGS` を設定する代わりに、環境変数 `LD_LIBRARY_PATH` にライブラリのディレクトリを指定しても動作します（コンパイル時と実行時の両方で設定してください）。
  * `USE_SYSTEM_*` フラグの使用には注意が必要です。これらは、Julia が正しくビルドされるよう Julia 開発者と緊密に連携するパッケージメンテナーが、トラブルシューティング、移植、パッケージングを行う場合にのみ使用することを想定しています。本番環境では、公式に提供されているバイナリを使用してください。これらのフラグの使用に起因する問題は、通常、受け付けられません。
  * [external dependencies](build.md#required-build-tools-and-external-libraries) も参照してください。

## Architecture Customization

`Make.user` ファイルで Makefile 変数 `ARCH` を設定すると、汎用ではないアーキテクチャ向けに Julia をビルドできます。`MARCH` や [`JULIA_CPU_TARGET`](@ref JULIA_CPU_TARGET) など、追加のカスタマイズオプションについては、`Make.inc` の該当セクションを参照してください。

たとえば Pentium 4 向けにビルドするには、`MARCH=pentium4` を設定し、リンクに必要なシステムライブラリをインストールします。Ubuntu では、lib32gfortran-6-dev、lib32gcc1、lib32stdc++6 などが必要になる場合があります。

現在のマシンの CPU に合わせて最大限の性能を引き出すビルドを行うには、`Make.user` で `MARCH=native` を設定することもできます。
