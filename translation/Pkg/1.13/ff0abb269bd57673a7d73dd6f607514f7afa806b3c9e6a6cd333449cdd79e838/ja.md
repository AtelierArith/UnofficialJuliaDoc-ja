```julia
Pkg.dependencies()::Dict{UUID, PackageInfo}
```

この機能は実験的なものです。

アクティブなプロジェクトの依存関係グラフを照会します。結果は、パッケージ UUID を、その依存関係（パッケージ）を表す `PackageInfo` 構造体に対応付ける `Dict` です。

# `PackageInfo` fields

| フィールド                  | 説明                                              |
|:---------------------- |:----------------------------------------------- |
| `name`                 | パッケージ名                                          |
| `version`              | パッケージのバージョン（標準ライブラリの場合は `Nothing`）              |
| `tree_hash`            | パッケージのディレクトリツリーのファイルハッシュ                        |
| `is_direct_dep`        | パッケージが直接の依存関係かどうか                               |
| `is_pinned`            | パッケージが固定されているかどうか                               |
| `is_tracking_path`     | パッケージがパスを追跡しているかどうか                             |
| `is_tracking_repo`     | パッケージがリポジトリを追跡しているかどうか                          |
| `is_tracking_registry` | パッケージがレジストリによって追跡されているかどうか（パスまたはリポジトリによる追跡ではない） |
| `git_revision`         | リポジトリを追跡している場合の Git リビジョン                       |
| `git_source`           | リポジトリを追跡している場合の Git ソース                         |
| `source`               | パッケージのソースコードを含むディレクトリ                           |
| `dependencies`         | UUID のベクターとして表した、そのパッケージの依存関係                   |
