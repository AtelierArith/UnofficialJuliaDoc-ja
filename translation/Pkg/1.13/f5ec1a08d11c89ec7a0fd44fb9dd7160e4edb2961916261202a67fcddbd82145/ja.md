```julia
Pkg.project()::ProjectInfo
```

この機能は実験的なものです。

アクティブなプロジェクトに関する情報を含む `ProjectInfo` 構造体を要求します。

# `ProjectInfo` fields

| フィールド          | 説明                                          |
|:-------------- |:------------------------------------------- |
| `name`         | プロジェクト名                                     |
| `uuid`         | プロジェクトの UUID                                |
| `version`      | プロジェクトのバージョン                                |
| `ispackage`    | プロジェクトがパッケージかどうか（名前と UUID を持つかどうか）          |
| `dependencies` | プロジェクトの直接依存関係。依存関係名を依存関係 UUID に対応付ける `Dict` |
| `path`         | アクティブなプロジェクトを定義するプロジェクトファイルの場所              |
