```julia
jump_128!(rng::Xoshiro, [n::Integer=1])
```

8 バイト（つまり `UInt64` 全体）を消費する `2^128` 回分に相当するだけ、状態を進めます。

`n > 0` が指定されている場合、状態は `n * 2^128` 回分に相当するだけ進みます。`n = 0` の場合、状態は変わりません。

これは、並列計算用に重複しない `2^128` 個の部分列を生成するために使用できます。

関連項目: [`jump_128`](@ref)、[`jump_192!`](@ref)

# Examples

```julia-repl
julia> jump_128!(jump_128!(Xoshiro(1))) == jump_128!(Xoshiro(1), 2)
true
```
