```julia
rand([rng=default_rng()], [S], [dims...])
```

`S`で指定された値の集合から、ランダムな要素を1つ、またはランダムな要素の配列を選びます。`S`には、次のいずれかを指定できます。

  * インデックスでアクセスできるコレクション（例：`1:9`または`('x', "y", :z)`）
  * `AbstractDict`または`AbstractSet`オブジェクト
  * 文字列（文字のコレクションとして扱われます）
  * 以下の型。指定した値の集合に対応します。

      * 具象整数型の場合、`typemin(S):typemax(S)`からサンプリングします（ただし、サポートされていない[`BigInt`](@ref)を除きます）。
      * 具象浮動小数点型の場合、`[0, 1)`からサンプリングします。
      * 具象複素数型`Complex{T}`の場合、`T`がサンプリング可能な型であれば、実部と虚部をそれぞれ`T`に対応する値の集合から独立に選びます。`T`がサンプリング可能でない場合はサポートされません。
      * すべての`<:AbstractChar`型の場合、有効なUnicodeスカラー値の集合からサンプリングします。
      * ユーザー定義型と値の集合。実装方法については[Hooking into the `Random` API](@ref rand-api-hook)を参照してください。
      * サイズが既知で、`S`の各パラメーターがサンプリング可能な型であるタプル型。この場合、型`S`の値を返します。サイズが不明な`Tuple{Vararg{T}}`や、値でパラメーター化された`Tuple{1:2}`などのタプル型はサポートされません。
      * `Pair`型（例：`Pair{X, Y}`）。`X`と`Y`に対して`rand`が定義されている場合、ランダムなペアが生成されます。

`S`の既定値は[`Float64`](@ref)です。省略可能な`rng`以外に引数が1つだけ渡され、それが`Tuple`の場合、その引数は`dims`ではなく、値のコレクション（`S`）として解釈されます。

正規分布に従う数値については[`randn`](@ref)を、インプレースで操作する同等の関数については[`rand!`](@ref)および[`randn!`](@ref)を参照してください。

!!! compat "Julia 1.1"
    タプルとしての`S`のサポートには、Julia 1.1以降が必要です。


!!! compat "Julia 1.11"
    `Tuple`型としての`S`のサポートには、Julia 1.11以降が必要です。


# Examples

```julia-repl
julia> rand(Int, 2)
2-element Vector{Int64}:
 1339893410598768192
 1575814717733606317

julia> using Random

julia> rand(Xoshiro(0), Dict(1=>2, 3=>4))
3 => 4

julia> rand((2, 3))
3

julia> rand(Float64, (2, 3))
2×3 Matrix{Float64}:
 0.999717  0.0143835  0.540787
 0.696556  0.783855   0.938235
```

!!! note
    `rand(rng, s::Union{AbstractDict,AbstractSet})`の計算量は、`s`の長さに対して線形です。ただし、定数時間で実行できる最適化メソッドが利用可能な場合はこの限りではありません。該当するのは`Dict`、`Set`、および密な`BitSet`です。数回を超えて呼び出す場合は、代わりに`rand(rng, collect(s))`を使用するか、用途に応じて`rand(rng, Dict(s))`または`rand(rng, Set(s))`を使用してください。
