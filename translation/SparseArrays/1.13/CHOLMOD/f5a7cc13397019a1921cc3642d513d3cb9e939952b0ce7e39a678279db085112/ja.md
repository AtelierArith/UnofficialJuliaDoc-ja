```julia
ldlt(A::SparseMatrixCSC; shift = 0.0, check = true, perm=nothing) -> CHOLMOD.Factor
```

疎行列 `A` の ``LDL'`` 分解を計算します。`A` は、`SparseMatrixCSC` の [`SparseMatrixCSC`](@ref) または [`Symmetric`](@ref)/[`Hermitian`](@ref) ビューでなければなりません。`A` に型タグがない場合、それ自体が対称行列またはエルミート行列でなければならない点に注意してください。フィルインを抑える置換が使用されます。`F = ldlt(A)` は、`F\b` を用いて連立方程式 `A*x = b` を解くために最もよく使われます。返される分解オブジェクト `F` は、[`diag`](@ref)、[`det`](@ref)、[`logdet`](@ref)、[`inv`](@ref) の各メソッドにも対応しています。`F.L` を使うと、`F` から個々の因子を取り出せます。ただし、既定ではピボット選択が有効なため、分解は内部的に置換行列 `P` を伴う `A == P'*L*D*L'*P` として表現されます。`P` を考慮せずに `L` だけを使うと、誤った結果になります。置換の影響を反映するには、通常、`P'*L` に相当する `PtL = F.PtL` や、`L'*P` に相当する `LtP = F.UP` など、「結合された」因子を取り出すのが適切です。対応している因子の一覧は `:L, :PtL, :D, :UP, :U, :LD, :DU, :PtLD, :DUP` です。置換ベクトルは `F.p` で取得できます。これは `L*D*L' == A[p, p]` となるように定義されています。

`LD` 成分は、`sparse(F.LD)` を使って疎行列として実体化できます。他の成分は直接実体化できませんが、必要に応じて `sparse(F.LD)` と `F.p` から再構成できます。

関連するコレスキー分解とは異なり、``LDL'`` 分解では `A` が正定値である必要はありません。ただし、すべての首座小行列式が良条件である必要があり、これを満たさない場合は失敗します。

`check = true` の場合、分解に失敗するとエラーがスローされます。`check = false` の場合、[`issuccess`](@ref) を使って分解の有効性を確認する責任はユーザーにあります。

省略可能なキーワード引数 `shift` を設定すると、`A` ではなく `A+shift*I` の分解が計算されます。`perm` 引数を指定する場合は、CHOLMOD の既定の AMD 順序付けの代わりに使用する順序を表す、`1:size(A,1)` の置換でなければなりません。

`ldlt` より大幅に高速な場合がある分解については [`cholesky`](@ref) も参照してください。ただし、こちらは `A` が正定値である必要があります。

!!! note
    このメソッドは、[SuiteSparse](https://github.com/DrTimothyAldenDavis/SuiteSparse) の CHOLMOD[^ACM887][^DavisHager2009] ライブラリを使用します。CHOLMOD が対応しているのは、単精度または倍精度の実数型と複素数型のみです。それ以外の要素型を持つ入力行列は、必要に応じてこれらの型に変換されます。

    CHOLMOD の他の多くの関数もラップされていますが、`Base.SparseArrays.CHOLMOD` モジュールからはエクスポートされていません。
