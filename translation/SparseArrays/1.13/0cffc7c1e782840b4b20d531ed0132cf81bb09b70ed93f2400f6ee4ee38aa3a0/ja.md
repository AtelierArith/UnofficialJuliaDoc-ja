```julia
SparseVector{Tv,Ti<:Integer} <: AbstractSparseVector{Tv,Ti}
```

疎ベクトルを格納するためのベクトル型です。ベクトルの長さ、ゼロでない要素のインデックスを*昇順に並べた*ベクトル、およびゼロでない要素の値を格納したベクトルを渡して作成できます。

たとえば、ベクトル `[5, 6, 0, 7]` は、次のように表せます。

```julia
SparseVector(4, [1, 2, 4], [5, 6, 7])
```

これは、インデックス1の要素が5、インデックス2の要素が6、インデックス3の要素が `zero(Int)`、インデックス4の要素が7であることを示しています。

密ベクトルから `sparse` を使って疎ベクトルを直接作成するほうが便利な場合もあります。次のコードは、

```julia
sparse([5, 6, 0, 7])
```

同じ疎ベクトルを生成します。
