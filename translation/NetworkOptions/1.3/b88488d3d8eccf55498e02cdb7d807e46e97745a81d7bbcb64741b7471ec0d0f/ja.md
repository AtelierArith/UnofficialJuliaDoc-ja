```julia
ca_roots_path() :: String
```

`ca_roots_path()` 関数は `ca_roots()` 関数と似ていますが、PEM エンコードされた認証局ルート証明書を含むファイルまたはディレクトリのパスを必ず返します。Windows や macOS のように、システムのルート証明書がファイルシステムに保存されていない環境で呼び出すと、現時点では Julia に同梱されているルート証明書一式へのパスを返します。（将来的には、システムからルート証明書を取得してファイルに保存し、そのファイルのパスを返すようになる可能性があります。）

TLS を使用するライブラリをシステム証明書で設定できる場合は、通常その方法が望ましいです。つまり、システム証明書を使用することを示す `nothing` を返す `ca_roots()` を使う方が適切です。`ca_roots_path()` 関数は、ルート証明書のファイルまたはディレクトリのパスを必須とするライブラリを設定する場合にのみ使用してください。

`ca_roots_path()` が返すデフォルト値は、`JULIA_SSL_CA_ROOTS_PATH`、`SSL_CERT_DIR`、または `SSL_CERT_FILE` 環境変数を設定することで上書きできます。この場合、この関数は、これらの変数のうち最初に設定されているものの値を常に返します（パスが存在するかどうかは問いません）。`JULIA_SSL_CA_ROOTS_PATH` が空文字列に設定されている場合、他の変数は（未設定の場合と同様に）無視されます。他の変数が空文字列に設定されている場合は、未設定の場合と同じように扱われます。
