```julia
ca_roots_path() :: String
```

`ca_roots_path()` 関数は `ca_roots()` 関数と似ていますが、PEM 形式でエンコードされた認証局のルート証明書を含むファイルまたはディレクトリのパスを常に返します。Windows や macOS のように、システムのルート証明書がファイルシステムに保存されていない環境で呼び出すと、現時点では Julia に同梱されているルート証明書一式へのパスを返します。（将来的には、この関数がシステムからルート証明書を取得してファイルに保存し、そのファイルのパスを返すようになる可能性があります。）

TLS を使用するライブラリをシステム証明書で設定できる場合は、通常その方法が望ましいです。つまり、システム証明書を使用することを示す `nothing` を返す `ca_roots()` を使うほうが適切です。`ca_roots_path()` 関数は、ルート証明書を含むファイルまたはディレクトリのパスを必須とするライブラリを設定する場合にのみ使用してください。

`ca_roots_path()` が返すデフォルト値は、環境変数 `JULIA_SSL_CA_ROOTS_PATH`、`SSL_CERT_DIR`、または `SSL_CERT_FILE` を設定することで上書きできます。この場合、この関数は設定されている変数のうち最初のものの値を常に返します（パスが存在するかどうかは問いません）。`JULIA_SSL_CA_ROOTS_PATH` が空文字列に設定されている場合、ほかの変数は未設定の場合と同様に無視されます。ほかの変数が空文字列に設定されている場合は、未設定の場合と同様に扱われます。
