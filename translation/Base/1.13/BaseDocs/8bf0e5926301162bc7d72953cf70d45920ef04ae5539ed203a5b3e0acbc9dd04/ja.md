```julia
Task(func[, reserved_stack::Int])
```

指定された関数 `func`（引数なしで呼び出せる必要があります）を実行するための `Task`（コルーチン）を作成します。この関数が戻るとタスクは終了します。タスクは、作成時に親から引き継いだ「ワールドエイジ」で実行されます。[`schedule`](@ref)d

省略可能な引数 `reserved_stack` は、このタスクで使用できるスタックのサイズをバイト単位で指定します。デフォルトの `0` では、システムに応じたデフォルトのスタックサイズが使用されます。

!!! warning
    デフォルトでは、タスクの sticky ビットは true に設定されます `t.sticky`。これは [`@async`](@ref) の従来のデフォルト動作を再現するものです。sticky タスクは、最初にスケジュールされたワーカースレッドでのみ実行できます。また、スケジュールされると、そのタスクをスケジュールしたタスクも sticky になります。[`Threads.@spawn`](@ref) の動作にするには、sticky ビットを手動で `false` に設定します。


# Examples

```jldoctest
julia> a() = sum(i for i in 1:1000);

julia> b = Task(a);
```

この例では、`b` は、まだ開始されていない実行可能な `Task` です。
