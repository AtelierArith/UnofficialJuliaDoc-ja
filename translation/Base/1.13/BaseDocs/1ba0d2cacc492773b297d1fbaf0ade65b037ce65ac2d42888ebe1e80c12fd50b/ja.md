タプルは、異なる型の値を格納できる固定長のコンテナです。ただし、変更はできません（イミュータブルです）。値にはインデックスでアクセスできます。タプルリテラルは、カンマと括弧を使って記述します。

```jldoctest
julia> (1, 1+1)
(1, 2)

julia> (1,)
(1,)

julia> x = (0.0, "hello", 6*7)
(0.0, "hello", 42)

julia> x[2]
"hello"

julia> typeof(x)
Tuple{Float64, String, Int64}
```

長さ1のタプルは、カンマを付けて記述する必要があります（`(1,)`）。`(1)`だけでは、値を括弧で囲んだものにすぎないためです。`()`は、空（長さ0）のタプルを表します。

イテレータからタプルを構築するには、`Tuple`型をコンストラクタとして使います。

```jldoctest
julia> Tuple(["a", 1])
("a", 1)

julia> Tuple{String, Float64}(["a", 1])
("a", 1.0)
```

タプル型の型パラメータは共変です。つまり、`Tuple{Int}`は`Tuple{Any}`のサブタイプです。そのため、`Tuple{Any}`は抽象型とみなされ、タプル型が具象型となるのは、その型パラメータが具象型である場合に限られます。タプルにはフィールド名がなく、フィールドにはインデックスでのみアクセスできます。タプル型の型パラメータの数に制限はありません。
