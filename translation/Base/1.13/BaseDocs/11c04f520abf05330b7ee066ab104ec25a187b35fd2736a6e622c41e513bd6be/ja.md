```julia
const
```

`const`は、値が変わらないグローバル変数を宣言するために使います。ほとんどのコード、特に性能が重要なコードでは、グローバル変数をこの方法で定数として宣言する必要があります。

```julia
const x = 5
```

1つの`const`内で、複数の変数を宣言できます。

```julia
const y, z = 7, 11
```

`const`は1つの`=`演算にのみ適用されるため、`const x = y = 1`では`x`は定数として宣言されますが、`y`は定数として宣言されません。一方、`const x = const y = 1`では、`x`と`y`の両方が定数として宣言されます。

「定数であること」は、変更可能なコンテナの中身には及びません。定数なのは、変数とその値との結び付きだけです。たとえば、`x`が配列や辞書であれば、要素の変更、追加、削除は引き続き可能です。

場合によっては、`const`変数の値を変更してもエラーではなく警告が表示されます。しかし、予測できない動作やプログラムの状態の破損につながる可能性があるため、変更は避けてください。この機能は、対話的な使用時の利便性のみを目的としています。
