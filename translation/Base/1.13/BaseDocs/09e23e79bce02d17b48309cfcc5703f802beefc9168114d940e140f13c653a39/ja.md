```julia
quote
```

`quote` は、明示的な [`Expr`](@ref) コンストラクターを使わずに、ブロック内に複数の式オブジェクトを作成します。たとえば、次のようになります。

```julia
ex = quote
    x = 1
    y = 2
    x + y
end
```

もう一方の引用方法である `:( ... )` とは異なり、この形式では式ツリーに `QuoteNode` 要素が追加されるため、ツリーを直接操作する際にはその点を考慮する必要があります。それ以外の用途では、`:( ... )` ブロックと `quote .. end` ブロックは同じように扱われます。
