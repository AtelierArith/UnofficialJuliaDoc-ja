```julia
.=
```

ブロードキャスト代入を実行します。右辺の引数は[`broadcast`](@ref)と同様に展開され、左辺の引数にインプレースで代入されます。同じ式内の他のドット演算子と融合します。つまり、代入式全体が単一のループに変換されます。

`A .= B`は`broadcast!(identity, A, B)`に似ています。

# Examples

```jldoctest
julia> A = zeros(4, 4); B = [1, 2, 3, 4];

julia> A .= B
4×4 Matrix{Float64}:
 1.0  1.0  1.0  1.0
 2.0  2.0  2.0  2.0
 3.0  3.0  3.0  3.0
 4.0  4.0  4.0  4.0

julia> A
4×4 Matrix{Float64}:
 1.0  1.0  1.0  1.0
 2.0  2.0  2.0  2.0
 3.0  3.0  3.0  3.0
 4.0  4.0  4.0  4.0
```
