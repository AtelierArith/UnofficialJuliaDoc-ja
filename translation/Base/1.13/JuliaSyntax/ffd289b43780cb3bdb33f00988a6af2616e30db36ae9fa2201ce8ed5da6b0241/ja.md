```julia
register_kinds!(mod, module_id, names)
```

指定した `names` を持つカスタム `Kind` を、モジュール `mod` に登録します。`names` は、任意の文字列の配列です。

種類を少ないビット数で表現するには、カスタム種類を使用するモジュール間で、次のように連携する必要があります。

  * 整数 `module_id` は、同時に使用する各 `mod` についてグローバルに一意であり、63 以下でなければなりません。
  * 複数のモジュールが同じ `name` を登録してはなりません。各 `kind` 名の意味は、それを所有するモジュールが定義する必要があります。

種類の範囲を区切り、すばやく判定できるように、特別な名前を使用できます。`BEGIN_section` と `END_section` のペアが検出され、それぞれ次および前の種類 ID の別名となるため、`section` 内の種類を `BEGIN_section <= k <= END_section` で判定できます。
