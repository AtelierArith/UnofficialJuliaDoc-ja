```julia
unsafe_swap!(p::Ptr{T}, x, [order::Symbol])
```

これらの関数は、メモリアドレスの値の取得と設定を不可分に同時実行します。ハードウェアが対応している場合は、適切なハードウェア命令に最適化されることがあります。対応していない場合、実行は次のようなものになります。

```julia
y = unsafe_load(p)
unsafe_store!(p, x)
return y
```

この関数名の接頭辞`unsafe`は、ポインタ`p`が有効かどうかの検証を行わないことを示しています。Cと同様に、この関数の呼び出し中に参照先のメモリが解放されたり、ガベージコレクションされたりしないようにする責任はプログラマーにあります。誤った使い方をすると、プログラムがセグフォルトを起こす可能性があります。

!!! compat "Julia 1.10"
    この関数を使用するには、Julia 1.10以降が必要です。
