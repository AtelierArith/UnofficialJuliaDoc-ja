```julia
mod1(x, y)
```

床除算後の剰余。正の `y` に対しては ``(0, y]`` の範囲、負の `y` に対しては ``[y,0)`` の範囲にある値 `r` を返します。ここで `mod(r, y) == mod(x, y)` です。

整数の引数と正の `y` を指定した場合、これは `mod(x, 1:y)` と等しくなるため、1 始まりのインデックス付けに適しています。一方、オフセットやストライドを使った計算には `mod(x, y) == mod(x, 0:y-1)` が適しています。

関連項目: [`mod`](@ref)、[`fld1`](@ref)、[`fldmod1`](@ref)。

# Examples

```jldoctest
julia> mod1(4, 2)
2

julia> mod1.(-5:5, 3)'
1×11 adjoint(::Vector{Int64}) with eltype Int64:
 1  2  3  1  2  3  1  2  3  1  2

julia> mod1.([-0.1, 0, 0.1, 1, 2, 2.9, 3, 3.1]', 3)
1×8 Matrix{Float64}:
 2.9  3.0  0.1  1.0  2.0  2.9  3.0  0.1
```
