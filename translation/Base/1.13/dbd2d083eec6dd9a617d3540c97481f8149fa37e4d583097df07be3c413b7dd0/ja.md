```julia
zhi, zlo = add12(x, y)
```

浮動小数点数を高精度で表現したものが `x + y` です。数学的には `zhi + zlo = x + y` であり、`zhi` が上位ビット、`zlo` が下位ビットを保持します。

浮動小数点数の表示方法のため、2進表現としては正確であっても、10進表現の観点からは `lo` が期待どおりに見えないことがあります。

例：

```jldoctest
julia> 1.0 + 1.0001e-15
1.000000000000001

julia> big(1.0) + big(1.0001e-15)
1.000000000000001000100000000000020165767380775934141445417482375879192346701529

julia> hi, lo = Base.add12(1.0, 1.0001e-15)
(1.000000000000001, -1.1012302462515652e-16)

julia> big(hi) + big(lo)
1.000000000000001000100000000000020165767380775934141445417482375879192346701529
```

`lo` が 1.0e-19 と異なるのは、`hi` が答えの最初の16桁の10進数と正確には一致しないためです。
