```julia
zhi, zlo = add12(x, y)
```

浮動小数点数を表す`x + y`の高精度表現です。数学的には`zhi + zlo = x + y`であり、`zhi`が最上位ビットを、`zlo`が最下位ビットを含みます。

浮動小数点数の表示方法のため、二進表現としては正確であっても、`lo`は十進表現の観点から期待するような見た目にならないことがあります。

例：

```jldoctest
julia> 1.0 + 1.0001e-15
1.000000000000001

julia> big(1.0) + big(1.0001e-15)
1.000000000000001000100000000000020165767380775934141445417482375879192346701529

julia> hi, lo = Base.add12(1.0, 1.0001e-15)
(1.000000000000001, -1.1012302462515652e-16)

julia> big(hi) + big(lo)
1.000000000000001000100000000000020165767380775934141445417482375879192346701529
```

`lo`が1.0e-19と異なるのは、`hi`が答えの最初の16桁の十進数と正確には一致しないためです。
