式の評価中に配列の境界チェックを行わないようにします。

以下の例では、パフォーマンス向上のため、配列 `A` の要素 `i` を参照する際の範囲内チェックが省略されます。

```julia
function sum(A::AbstractArray)
    r = zero(eltype(A))
    for i in eachindex(A)
        @inbounds r += A[i]
    end
    return r
end
```

!!! warning
    範囲外のインデックスに対して `@inbounds` を使用すると、誤った結果が返されたり、クラッシュやデータ破損が発生したりする可能性があります。手動でのチェックはユーザーの責任です。すべてのアクセスが範囲内であると確信できる場合に限り、`@inbounds` を使用してください（この前提に反すると、クラッシュなどの未定義動作が発生する可能性があります）。たとえば、上記のような関数で `eachindex(A)` の代わりに `1:length(A)` を使用しても、安全に範囲内であるとは言えません。`A` の最初のインデックスは、`AbstractArray` のサブタイプであるすべてのユーザー定義型で `1` になるとは限らないためです。
