```julia
precompilepkgs(pkgs; kwargs...)
```

パッケージとその依存関係を、並列コンパイル、進捗状況の追跡、各種コンパイル設定に対応して事前コンパイルします。

`pkgs::Union{Vector{String}, Vector{PkgId}}`: 事前コンパイルするパッケージ。空の場合（デフォルト）は、プロジェクトのすべての依存関係を事前コンパイルします。指定した場合は、指定されたパッケージとその依存関係のみを事前コンパイルします（`manifest=true`の場合を除く）。

!!! note
    エラーがスローされるのは、トップレベルの依存関係を事前コンパイルするときだけです。これは、指定されたシステム上で、マニフェストに記載されたすべての依存関係がトップレベルの依存関係によって読み込まれるとは限らないためです。キーワード引数`strict`に`true`を設定すると、この動作を変更し、すべての依存関係でエラーをスローさせることができます。


# Keyword Arguments

  * `internal_call::Bool`: 外部（例: Pkg）からの自動事前コンパイル呼び出しであることを示します。このパラメーターは使用しないでください。
  * `strict::Bool`: エラー報告の範囲を制御します。`false`（デフォルト）の場合、プロジェクトの直接の依存関係についてのみエラーを報告します。`manifest=true`の場合にのみ有効です。
  * `warn_loaded::Bool`: `true`（デフォルト）の場合、事前コンパイル済みだが異なるバージョンがすでに読み込まれているパッケージを確認し、警告します。新たに事前コンパイルされたバージョンを使用するにはJuliaを再起動する必要があることを示す警告が表示されます。
  * `timing::Bool`: `true`（デフォルトでは無効）の場合、コンパイルが成功した可能性があるときに限り、パッケージごとのコンパイル時間を表示します。装飾的な進捗バーの表示は無効になり、時間はシンプルなテキスト形式で表示されます。
  * `_from_loading::Bool`: 呼び出し元がパッケージ読み込みシステムであることを示す内部フラグです。`true`（デフォルトでは無効）の場合、パッケージが見つからなくても例外をスローせずに早期リターンします。対話型セッションでない場合は進捗メッセージを抑制し、現在の環境外のパッケージを直列事前コンパイルジョブとして追加できるようにし、LOADING_CACHEの初期化をスキップし、キャッシュファイルのロック動作を変更します。
  * `configs::Union{Config,Vector{Config}}`: 使用するコンパイル設定。各Configは、コマンドフラグとキャッシュフラグを指定する`Pair{Cmd, Base.CacheFlags}`です。複数の設定を指定すると、各パッケージは設定ごとに事前コンパイルされます。
  * `io::IO`: 進捗メッセージ、警告、エラーの出力先ストリーム。リダイレクトできます（例: 非対話モードでの読み込み時に呼び出された場合は`devnull`）。
  * `fancyprint::Bool`: 出力形式を制御します。`true`の場合、スピナー付きのアニメーション進捗バーを表示します。`false`の場合は、代わりに`timing`モードを有効にします。`timing=true`の場合、または非対話モードでの読み込み時には、自動的に無効になります。
  * `manifest::Bool`: 事前コンパイルするパッケージの範囲を制御します。`false`（デフォルト）の場合、`pkgs`で指定されたパッケージとその依存関係のみを事前コンパイルします。`true`の場合、マニフェスト内のすべてのパッケージを事前コンパイルします（ワークスペースモード）。通常、Pkgがワークスペースの事前コンパイルを要求するときに使用されます。
  * `ignore_loaded::Bool`: すでに読み込まれているパッケージがキャッシュの鮮度チェックに影響するかどうかを制御します。`false`（デフォルトでは無効）の場合、キャッシュファイルが最新かどうかを判定する際に、読み込み済みパッケージのバージョンも考慮されます。

# Return

  * `Vector{String}`: 要求されたパッケージのキャッシュファイルへのパス。
  * `Nothing`: 事前コンパイルをスキップする必要がある

# Notes

  * 循環依存関係にあるパッケージは、警告を出してスキップされます。
  * `__precompile__(false)`を持つパッケージは、セッションごとに同じ処理が繰り返されないよう、読み込み時に限りスキップされます。
  * 並列コンパイルは、環境変数`JULIA_NUM_PRECOMPILE_TASKS`で制御されます（デフォルトはCPU_THREADS + 1、最大16。Windowsではその半分）。
  * 拡張機能は、そのすべてのトリガーが環境内で利用可能な場合に事前コンパイルされます。
