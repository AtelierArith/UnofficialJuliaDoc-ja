```julia
Sys.EFFECTIVE_CPU_THREADS::Int
```

コンテナの制限（Docker `--cpus`、Kubernetes の CPU 制限、cgroup のクォータなど）を考慮した、Julia プロセスが利用できる論理 CPU コア数です。ハードウェアの CPU スレッド数と、適用されている CPU 制限のうち、少ない方の値になります。

コンテナ化されていない環境では、通常は `Sys.CPU_THREADS` と同じ値になります。コンテナ化された環境では cgroup の CPU 制限が反映されるため、利用可能な並列処理能力をより正確に把握できます。

コンテナ化された環境で適切に動作するよう、デフォルトのスレッドプールサイズや並列度を決める際に、この定数を使用してください。
