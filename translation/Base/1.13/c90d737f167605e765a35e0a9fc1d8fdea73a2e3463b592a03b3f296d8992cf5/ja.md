```julia
@raw_str -> String
```

補間やエスケープ処理を行わない raw 文字列を作成します。ただし、引用符はエスケープする必要があります。バックスラッシュは、引用符の前に連続して並んでいる場合に限り、引用符とほかのバックスラッシュの両方をエスケープします。したがって、引用符の前に 2n 個のバックスラッシュがある場合は n 個のバックスラッシュとリテラルの終端を表し、2n+1 個ある場合は n 個のバックスラッシュに続く引用符文字を表します。

# Examples

```jldoctest
julia> println(raw"\ $x")
\ $x

julia> println(raw"\"")
"

julia> println(raw"\\\"")
\"

julia> println(raw"\\x \\\"")
\\x \"
```
