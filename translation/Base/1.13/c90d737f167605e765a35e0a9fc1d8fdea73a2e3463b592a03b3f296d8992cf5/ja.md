```julia
@raw_str -> String
```

補間やエスケープ処理を行わない生文字列を作成します。ただし、引用符はエスケープする必要があります。バックスラッシュは、引用符の前に連続している場合に限り、引用符とほかのバックスラッシュの両方をエスケープします。したがって、引用符の前に2n個のバックスラッシュがある場合は、n個のバックスラッシュとリテラルの終端を表し、2n+1個ある場合は、n個のバックスラッシュに続く引用符文字を表します。

# Examples

```jldoctest
julia> println(raw"\ $x")
\ $x

julia> println(raw"\"")
"

julia> println(raw"\\\"")
\"

julia> println(raw"\\x \\\"")
\\x \"
```
