```julia
_xfadjoint(op, itr) -> op′, itr′
```

リダクション関数 `op` とイテレータ `itr` のペアを受け取り、同様の型からなるペア `(op′, itr′)` を返します。イテレータ `itr` がイテレータ変換 `ixf` によって変換されており、その随伴トランスデューサ `xf` が既知である場合は、`op′ = xf(op)` と `itr′ = ixf⁻¹(itr)` を返します。それ以外の場合は、`op` と `itr` をそのまま返します。たとえば、トランスデューサ `rf -> MappingRF(f, rf)` はイテレータ変換 `itr -> Generator(f, itr)` の随伴です。

入れ子になったイテレータ変換は再帰的に変換されます。つまり、`op` と次のものが与えられた場合、

```julia
itr = (ixf₁ ∘ ixf₂ ∘ ... ∘ ixfₙ)(itr′)
```

返されるのは `itr′` と次のものです。

```julia
op′ = (xfₙ ∘ ... ∘ xf₂ ∘ xf₁)(op)
```
