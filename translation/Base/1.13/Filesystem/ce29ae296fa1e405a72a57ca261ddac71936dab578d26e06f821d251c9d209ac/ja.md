```julia
StatStruct
```

ファイルに関する情報を格納する構造体です。通常は、パスを指定して [`stat`](@ref) を呼び出して作成します。

この構造体は、複数のユーティリティ関数の基盤として内部で使用されます。[`filesize`](@ref)、[`mtime`](@ref)、[`ctime`](@ref) のように、格納された情報の特定の部分をそのまま返す関数もあります。一方、[`isfifo`](@ref)、[`ischardev`](@ref)、[`issetuid`](@ref) のように、ビット操作を使って追加の処理を行う関数もあります。

この構造体の次のフィールドは、公開 API として扱われます。

| 名前      | 型                               | 説明                               |
|:------- |:------------------------------- |:-------------------------------- |
| desc    | `Union{String, Base.OS_HANDLE}` | パスまたは OS のファイル記述子                |
| size    | `Int64`                         | ファイルのサイズ（バイト単位）                  |
| device  | `UInt`                          | ファイルを格納しているデバイスの ID              |
| inode   | `UInt`                          | ファイルの inode 番号                   |
| mode    | `UInt`                          | ファイルの保護モード                       |
| nlink   | `Int`                           | ファイルへのハードリンク数                    |
| uid     | `UInt`                          | ファイル所有者のユーザー ID                  |
| gid     | `UInt`                          | ファイル所有者のグループ ID                  |
| rdev    | `UInt`                          | デバイスを参照するファイルの場合、参照先デバイスの ID     |
| blksize | `Int64`                         | ファイルシステムがファイルに推奨するブロックサイズ        |
| blocks  | `Int64`                         | 割り当てられた 512 バイトブロックの数            |
| mtime   | `Float64`                       | ファイルが最後に変更された時刻の Unix タイムスタンプ    |
| ctime   | `Float64`                       | ファイルのメタデータが変更された時刻の Unix タイムスタンプ |

関連項目: [`stat`](@ref)
