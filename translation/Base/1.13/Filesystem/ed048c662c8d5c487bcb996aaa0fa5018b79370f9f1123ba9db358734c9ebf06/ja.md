```julia
symlink(target::AbstractString, link::AbstractString; dir_target = false)
```

`target`へのシンボリックリンクを、`link`という名前で作成します。

Windowsでは、シンボリックリンクがディレクトリを参照するかどうかを明示的に指定する必要があります。`target`がすでに存在する場合、デフォルトでは`link`の種類が自動検出されます。ただし、`target`が存在しない場合、この関数はデフォルトでファイルへのシンボリックリンクを作成します。ただし、`dir_target`が`true`に設定されている場合は除きます。ユーザーが`dir_target`を設定していても、`target`が存在し、それがファイルである場合は、ディレクトリへのシンボリックリンクが作成されます。ただし、ディレクトリが作成される前に`dir_target`を`false`に設定して`symlink()`を呼び出し、ファイルへのシンボリックリンクを作成してから、それをディレクトリとして参照しようとした場合と同様に、リンク先の参照は失敗します。

また、Windowsでリンクを作成する方法には、シンボリックリンクとジャンクションポイントの2種類があります。ジャンクションポイントはやや効率的ですが、相対パスには対応していません。そのため、相対ディレクトリシンボリックリンクが要求された場合（`isabspath(target)`が`false`を返すことで判定）、シンボリックリンクが使用され、それ以外の場合はジャンクションポイントが使用されます。Windowsでシンボリックリンクを作成する際は、参照先のファイルやディレクトリを作成してからリンクを作成するのがベストプラクティスです。

関連項目: [`hardlink`](@ref)。

!!! note
    Windows XPなど、ソフトシンボリックリンクをサポートしないオペレーティングシステムでは、この関数はエラーを発生させます。


!!! compat "Julia 1.6"
    `dir_target`キーワード引数はJulia 1.6で追加されました。それ以前は、Windowsでは存在しないパスへのシンボリックリンクは常にファイルへのリンクとなり、ディレクトリへの相対シンボリックリンクはサポートされていませんでした。
