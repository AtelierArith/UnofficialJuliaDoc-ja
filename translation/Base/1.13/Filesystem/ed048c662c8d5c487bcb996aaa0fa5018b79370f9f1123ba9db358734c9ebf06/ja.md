```julia
symlink(target::AbstractString, link::AbstractString; dir_target = false)
```

`target`へのシンボリックリンクを、`link`という名前で作成します。

Windowsでは、シンボリックリンクがディレクトリを指すかどうかを明示する必要があります。`target`がすでに存在する場合、デフォルトでは`link`の種類が自動判定されます。ただし、`target`が存在しない場合、この関数はデフォルトでファイルへのシンボリックリンクを作成します。ただし、`dir_target`が`true`に設定されている場合は除きます。ユーザーが`dir_target`を設定していても、`target`が存在し、それがファイルである場合、ディレクトリへのシンボリックリンクが作成されますが、リンク先をたどるとエラーになります。これは、ディレクトリを作成する前に`dir_target`を`false`に設定して`symlink()`を呼び出し、ファイルへのシンボリックリンクを作成してから、そのリンクをたどってディレクトリにアクセスしようとした場合と同様です。

また、Windowsでリンクを作成する方法には、シンボリックリンクとジャンクションポイントの2種類があります。ジャンクションポイントはやや効率的ですが、相対パスには対応していません。そのため、相対パスのディレクトリシンボリックリンクが要求された場合（`isabspath(target)`が`false`を返す場合）はシンボリックリンクが使われ、それ以外の場合はジャンクションポイントが使われます。Windowsでシンボリックリンクを作成する際は、参照先のファイルやディレクトリを作成してからリンクを作成するのがベストプラクティスです。

関連項目: [`hardlink`](@ref)。

!!! note
    Windows XPなど、ソフトシンボリックリンクに対応していないオペレーティングシステムでは、この関数はエラーを発生させます。


!!! compat "Julia 1.6"
    `dir_target`キーワード引数はJulia 1.6で追加されました。それ以前は、Windowsでは存在しないパスへのシンボリックリンクは常にファイルへのリンクとなり、ディレクトリへの相対シンボリックリンクには対応していませんでした。
