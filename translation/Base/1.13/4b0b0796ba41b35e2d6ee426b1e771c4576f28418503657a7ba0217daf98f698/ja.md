```julia
merge(a::NamedTuple, bs::NamedTuple...)
```

2つ以上の既存の名前付きタプルを左結合でマージし、新しい名前付きタプルを作成します。マージは名前付きタプルのペアごとに左から右へ進みます。そのため、最左の名前付きタプルと最右の名前付きタプルの両方に存在するフィールドは、最左の名前付きタプルでの位置を保ちます。ただし、値には、そのフィールドを含む最右の名前付きタプルのものが使われます。ペアの右側の名前付きタプルにのみ存在するフィールドは末尾に追加されます。名前付きタプルが1つだけ指定された場合に備えて、次のシグネチャを持つフォールバックが実装されています。`merge(a::NamedTuple)`

!!! compat "Julia 1.1"
    3つ以上の`NamedTuple`をマージするには、Julia 1.1以降が必要です。


# Examples

```jldoctest
julia> merge((a=1, b=2, c=3), (b=4, d=5))
(a = 1, b = 4, c = 3, d = 5)
```

```jldoctest
julia> merge((a=1, b=2), (b=3, c=(d=1,)), (c=(d=2,),))
(a = 1, b = 3, c = (d = 2,))
```
