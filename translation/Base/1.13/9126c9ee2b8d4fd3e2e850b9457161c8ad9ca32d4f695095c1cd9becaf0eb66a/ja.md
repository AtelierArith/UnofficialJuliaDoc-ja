```julia
extrema(f, itr; [init]) -> (mn, mx)
```

`itr` の各要素に `f` を適用し、その最小値 `mn` と最大値 `mx` を計算して、2 タプルとして返します。`itr` は 1 回だけ走査されます。

空の `itr` に対して返す値は、`init` で指定できます。これは、1 番目と 2 番目の要素がそれぞれ `min` と `max` の中立元（つまり、ほかのどの要素よりも大きいか等しい値、および小さいか等しい値）である 2 タプルでなければなりません。これは空でないコレクションに対して使用されます。注: 空の `itr` の場合、返される値 `(mn, mx)` は `mn ≥ mx` を満たしますが、空でない `itr` の場合は `mn ≤ mx` を満たします。これは「逆説的」ですが、想定どおりの結果です。

!!! compat "Julia 1.2"
    このメソッドには Julia 1.2 以降が必要です。


!!! compat "Julia 1.8"
    キーワード引数 `init` には Julia 1.8 以降が必要です。


# Examples

```jldoctest
julia> extrema(sin, 0:π)
(0.0, 0.9092974268256817)

julia> extrema(sin, Real[]; init = (1.0, -1.0))  # good, since -1 ≤ sin(::Real) ≤ 1
(1.0, -1.0)
```
