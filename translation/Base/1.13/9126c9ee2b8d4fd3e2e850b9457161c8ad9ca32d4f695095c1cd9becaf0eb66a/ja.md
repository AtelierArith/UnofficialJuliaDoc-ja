```julia
extrema(f, itr; [init]) -> (mn, mx)
```

`itr` の各要素に適用した `f` の最小値 `mn` と最大値 `mx` の両方を計算し、2 タプルとして返します。`itr` は 1 回だけ走査されます。

空の `itr` に対して返す値は、`init` で指定できます。これは、`min` と `max` のそれぞれに対する中立元（つまり、他のどの要素よりも大きいか等しい要素、および小さいか等しい要素）を第 1 要素と第 2 要素に持つ 2 タプルでなければなりません。この値は、空でないコレクションに対して使用されます。注：このため、空の `itr` では、返される値 `(mn, mx)` は `mn ≥ mx` を満たしますが、空でない `itr` では `mn ≤ mx` を満たします。これは「逆説的」ですが、想定どおりの結果です。

!!! compat "Julia 1.2"
    このメソッドには Julia 1.2 以降が必要です。


!!! compat "Julia 1.8"
    キーワード引数 `init` には Julia 1.8 以降が必要です。


# Examples

```jldoctest
julia> extrema(sin, 0:π)
(0.0, 0.9092974268256817)

julia> extrema(sin, Real[]; init = (1.0, -1.0))  # good, since -1 ≤ sin(::Real) ≤ 1
(1.0, -1.0)
```
