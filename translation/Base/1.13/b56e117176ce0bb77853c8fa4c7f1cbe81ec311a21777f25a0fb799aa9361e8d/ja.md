```julia
fld(x, y)
```

`x / y` 以下の最大の整数。`div(x, y, RoundDown)` と同等です。

関連項目: [`div`](@ref)、[`cld`](@ref)、[`fld1`](@ref)。

# Examples

```jldoctest
julia> fld(7.3, 5.5)
1.0

julia> fld.(-5:5, 3)'
1×11 adjoint(::Vector{Int64}) with eltype Int64:
 -2  -2  -1  -1  -1  0  0  0  1  1  1
```

`fld(x, y)` は、浮動小数点数の真の値に基づいて厳密に正しい切り下げ丸めを行うため、直感に反する状況が生じることがあります。たとえば、次のようになります。

```jldoctest
julia> fld(6.0, 0.1)
59.0
julia> 6.0 / 0.1
60.0
julia> 6.0 / big(0.1)
59.99999999999999666933092612453056361837965690217069245739573412231113406246995
```

ここで起きているのは、`0.1` と表記される浮動小数点数の真の値が数値 1/10 よりわずかに大きい一方、`6.0` は数値 6 を正確に表しているということです。そのため、`6.0 / 0.1` の真の値は 60 よりわずかに小さくなります。除算を行うと、これはちょうど `60.0` に丸められますが、`fld(6.0, 0.1)` は常に真の値を切り下げるため、結果は `59.0` になります。
