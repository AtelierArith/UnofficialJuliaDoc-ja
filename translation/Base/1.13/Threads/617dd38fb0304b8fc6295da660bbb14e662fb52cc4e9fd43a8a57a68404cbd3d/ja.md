```julia
resize_nthreads!(A, copyvalue=A[1])
```

配列 `A` の長さを [`nthreads()`](@ref) に変更します。新たに割り当てられた要素は `deepcopy(copyvalue)` で初期化されます。`copyvalue` の既定値は `A[1]` です。

これは通常、スレッドごとの変数を割り当てるために使われます。`A` がグローバル定数の場合は、`__init__` 内で呼び出してください。

!!! warning
    Julia v1.9 以降、実行時にスレッド数を変更できるため、この関数は非推奨です。代わりに、呼び出し元のスレッド ID に基づいて、必要に応じてスレッドごとの状態を作成してください。
