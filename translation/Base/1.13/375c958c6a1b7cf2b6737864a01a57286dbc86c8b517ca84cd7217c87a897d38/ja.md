```julia
one(x)
one(T::Type)
```

`x`の乗法単位元を返します。つまり、`one(x)*x == x*one(x) == x`を満たす値です。乗法単位元が型だけから決まる場合は、`one`の引数に型を指定できます（たとえば、`one(Int)`は、`Int`のすべてのインスタンスで乗法単位元が同じなので機能します。一方、形状の異なる行列では乗法単位元も異なるため、`one(Matrix{Int})`は定義されていません）。

可能であれば、`one(x)`は`x`と同じ型の値を返し、`one(T)`は`T`型の値を返します。ただし、時間（日単位）など、次元を持つ量を表す型では、乗法単位元は無次元でなければならないため、そうならない場合があります。その場合、`one(x)`は`x`と同じ精度（行列の場合は形状も）の単位元を返します。

`x`と同じ型、または`T`型の量が必要で、`x`が次元を持つ場合も含めて、そのような量を得るには、代わりに[`oneunit`](@ref)を使用してください。

[`identity`](@ref)関数、および単位行列については[`LinearAlgebra`](@ref man-linalg)の`I`も参照してください。

# Examples

```jldoctest
julia> one(3.7)
1.0

julia> one(Int)
1

julia> import Dates; one(Dates.Day(1))
1
```
