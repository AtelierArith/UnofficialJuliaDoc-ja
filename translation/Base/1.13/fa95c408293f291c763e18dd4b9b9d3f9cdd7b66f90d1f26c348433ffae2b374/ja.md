```julia
===(x,y)::Bool
≡(x,y)::Bool
```

`x` と `y` が、どのプログラムからも区別できないという意味で同一かどうかを判定します。まず、`x` と `y` の型を比較します。型が同一であれば、可変オブジェクトはメモリ上のアドレスで比較され、不変オブジェクト（数値など）はビット単位の内容で比較されます。この関数は「egal」と呼ばれることもあります。戻り値は常に `Bool` です。

# Examples

```jldoctest
julia> a = [1, 2]; b = [1, 2];

julia> a == b
true

julia> a === b
false

julia> a === a
true
```
