```julia
gcdx(a, b...)
```

`a` と `b` の最大公約数（正の値）と、ベズー係数、すなわち ``u*a + v*b = d = gcd(a, b)`` を満たす整数係数 `u` および `v` を計算します。``gcdx(a, b)`` は ``(d, u, v)`` を返します。

引数が2つより多い場合、すなわち `gcdx(a, b, c, ...)`、ベズー係数を再帰的に計算し、``u*a + v*b + w*c + ... = d = gcd(a, b, c, ...)`` に対する解 `(d, u, v, w, ...)` を返します。

引数には整数および有理数を指定できます。

!!! compat "Julia 1.4"
    有理数の引数を使用するには、Julia 1.4 以降が必要です。


!!! compat "Julia 1.12"
    引数が2つより多い場合、または2つより少ない場合は、Julia 1.12 以降が必要です。


# Examples

```jldoctest
julia> gcdx(12, 42)
(6, -3, 1)

julia> gcdx(240, 46)
(2, -9, 47)

julia> gcdx(15, 12, 20)
(1, 7, -7, -1)
```

!!! note
    ベズー係数は一意に定まりません。`gcdx` は、拡張ユークリッドの互除法で計算される最小のベズー係数を返します（参考: D. Knuth, TAoCP, 第2版、p. 325、Algorithm X）。符号付き整数の場合、これらの係数 `u` および `v` は、``|u| < |b/d|`` および ``|v| < |a/d|`` となる意味で最小です。さらに、`u` および `v` の符号は、`d` が正になるように選ばれます。符号なし整数の場合、係数 `u` および `v` は、それぞれの `typemax` に近い値になることがあり、その場合、この等式は符号なし整数の剰余演算によってのみ成り立ちます。
