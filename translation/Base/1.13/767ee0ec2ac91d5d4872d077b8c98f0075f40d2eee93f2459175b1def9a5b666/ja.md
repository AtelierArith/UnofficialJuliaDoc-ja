```julia
eps(::Type{T}) where T<:AbstractFloat
eps()
```

浮動小数点型 `T`（デフォルトでは `T = Float64`）の*機械イプシロン*を返します。これは、`typeof(one(T))`で表現可能な 1 と、その次に大きい値との間隔として定義され、`eps(one(T))`と等価です。（`eps(T)`は、`T`の*相対誤差*の上限であるため、[`one`](@ref)と同様に「無次元」の量です。）

# Examples

```jldoctest
julia> eps()
2.220446049250313e-16

julia> eps(Float32)
1.1920929f-7

julia> 1.0 + eps()
1.0000000000000002

julia> 1.0 + eps()/2
1.0
```

より一般に、任意の浮動小数点数値型について、`eps`は、最も近い浮動小数点複素数値までの距離の上限に相当します。数値 ``x``（任意の実数など）に最も近い浮動小数点値が ``ext{fl}(x)``である場合、オーバーフローする場合を除き、``ext{fl}(x)``は ``|x - 	ext{fl}(x)| ≤ 	ext{eps}(x)/2``を満たします。これにより、`eps`の定義を複素数にも拡張できます。この場合、``ext{fl}(a + ib) = 	ext{fl}(a) + i 	ext{fl}(b)``となります。
