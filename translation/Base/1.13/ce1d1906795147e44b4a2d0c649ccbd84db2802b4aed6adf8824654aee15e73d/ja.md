```julia
sum(f, itr; [init])
```

`itr` の各要素に対して関数 `f` を呼び出し、その結果を合計します。

システムワードサイズ未満の符号付き整数の場合、戻り値の型は `Int` です。システムワードサイズ未満の符号なし整数の場合は `UInt` です。それ以外の引数では、すべての引数が昇格される共通の戻り値の型が決定されます。

空の `itr` に対して返される値は、`init` で指定できます。これは加法単位元（つまりゼロ）でなければなりません。空でないコレクションでは `init` が使われるかどうかは規定されていないためです。

!!! compat "Julia 1.6"
    キーワード引数 `init` を使用するには、Julia 1.6 以降が必要です。


# Examples

```jldoctest
julia> sum(abs2, [2; 3; 4])
29
```

整数型の要素型が小さい配列では、`sum(A)` と `reduce(+, A)` の重要な違いに注意してください。

```jldoctest
julia> sum(Int8[100, 28])
128

julia> reduce(+, Int8[100, 28])
-128
```

前者の場合、整数はシステムワードサイズに拡張されるため、結果は 128 になります。後者の場合、そのような拡張は行われず、整数オーバーフローによって -128 になります。
