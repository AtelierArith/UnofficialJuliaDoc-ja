
パック形式で格納された QR 行列分解。通常、[`qr`](@ref) から得られます。``A`` が `m`×`n` 行列の場合、

```math
A = Q R
```

ここで、``Q`` は直交行列／ユニタリ行列、``R`` は上三角行列です。行列 ``Q`` は、ハウスホルダー反射 ``v_i`` と係数 ``\tau_i`` の列として格納されます。ここで、

```math
Q = \prod_{i=1}^{\min(m,n)} (I - \tau_i v_i v_i^T).
```

分解を反復すると、成分 `Q` と `R` が得られます。

このオブジェクトには2つのフィールドがあります。

  * `factors` は `m`×`n` 行列です。

      * 上三角部分には ``R`` の要素が格納されます。つまり、`QR` オブジェクト `F` では `R = triu(F.factors)` です。
      * 対角線より下の部分には、パック形式で格納された反射 ``v_i`` が格納されます。この形式では、``v_i`` は行列 `V = I + tril(F.factors, -1)` の ``i`` 列目です。
  * `τ` は長さ `min(m,n)` のベクトルで、係数 ``\tau_i`` を含みます。
