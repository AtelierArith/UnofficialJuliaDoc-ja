```julia
opnorm(A::AbstractMatrix, p::Real=2)
```

ベクトルの `p` ノルムによって誘導される作用素ノルム（または行列ノルム）を計算します。`p` に指定できる値は、`1`、`2`、`Inf` です。（疎行列では、現在 `p=2` は実装されていないことに注意してください。）フロベニウスノルムの計算には [`norm`](@ref) を使用します。

`p=1` の場合、作用素ノルムは `A` の列ごとの絶対値の和の最大値です。

```math
\|A\|_1 = \max_{1 ≤ j ≤ n} \sum_{i=1}^m | a_{ij} |
```

ここで、``a_{ij}`` は ``A`` の要素、``m`` と ``n`` はその次元です。

`p=2` の場合、作用素ノルムはスペクトルノルムであり、`A` の最大特異値に等しくなります。

`p=Inf` の場合、作用素ノルムは `A` の行ごとの絶対値の和の最大値です。

```math
\|A\|_\infty = \max_{1 ≤ i ≤ m} \sum _{j=1}^n | a_{ij} |
```

# Examples

```jldoctest
julia> A = [1 -2 -3; 2 3 -1]
2×3 Matrix{Int64}:
 1  -2  -3
 2   3  -1

julia> opnorm(A, Inf)
6.0

julia> opnorm(A, 1)
5.0
```
