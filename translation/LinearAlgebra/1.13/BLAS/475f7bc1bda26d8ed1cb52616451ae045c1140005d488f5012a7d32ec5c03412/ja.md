```julia
spmv!(uplo, α, AP, x, β, y)
```

`y` ベクトルを、`α*A*x + β*y` として更新します。`A` は、`AP` 形式で格納された対称行列です。

`uplo = 'U'` の場合、配列 AP には対称行列の上三角部分を列ごとに順に格納します。つまり、`AP[1]` には `A[1, 1]` が、`AP[2]` と `AP[3]` にはそれぞれ `A[1, 2]` と `A[2, 2]` が格納され、以降も同様です。

`uplo = 'L'` の場合、配列 AP には対称行列の下三角部分を列ごとに順に格納します。つまり、`AP[1]` には `A[1, 1]` が、`AP[2]` と `AP[3]` にはそれぞれ `A[2, 1]` と `A[3, 1]` が格納され、以降も同様です。

スカラー入力 `α` と `β` は実数でなければなりません。

配列入力 `x`、`y`、`AP` は、すべて `Float32` 型または `Float64` 型でなければなりません。

更新後の `y` を返します。

!!! compat "Julia 1.5"
    `spmv!` の使用には Julia 1.5 以降が必要です。
