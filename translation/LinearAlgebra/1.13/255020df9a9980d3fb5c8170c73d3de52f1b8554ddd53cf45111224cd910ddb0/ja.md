```julia
mul!(C::AbstractVecOrMat, tA, tB, A::AbstractVecOrMat, B::AbstractVecOrMat, α::Number, β::Number)
```

行列の転置を行う場合は `B` に対応する `tB` を指定し、行列同士の積和演算 ``A B α + C β`` (`tA == 'N'`)、``A^⊤ B α + C β`` (`tA == 'T'`)、または ``A' B α + C β`` (`tA == 'C'`) を計算します。結果は `C` に上書きして格納されます。`C` は `A` または `B` とエイリアスになっていてはならない点に注意してください。

これは、5 引数の [`mul!`](@ref) より下位の抽象化レイヤーです。独自のストレージ型を提供するパッケージでは、5 引数の `mul!` ではなく、このメソッドをオーバーロードすることを推奨します。

!!! compat "Julia 1.13"
    このメソッドは Julia 1.13 以降でのみ使用でき、同じシグネチャを持つ非公開の `generic_matmatmul!` メソッドに代わるものです。
