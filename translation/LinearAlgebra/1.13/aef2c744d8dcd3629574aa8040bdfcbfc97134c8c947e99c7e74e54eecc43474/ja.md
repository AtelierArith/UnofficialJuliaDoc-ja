```julia
mul!(c::AbstractVector, tA, A::AbstractVecOrMat, b::AbstractVector, α::Number, β::Number)
```

行列とベクトルの積和演算 ``A b α + c β`` (`tA == 'N'`)、``A^⊤ b α + c β`` (`tA == 'T'`)、または ``A' b α + c β`` (`tA == 'C'`) を計算します。結果は `c` に上書きして格納されます。`c` は `A` または `b` とエイリアスになってはならないことに注意してください。

これは、ストレージ型に応じたディスパッチに使用される、5 引数の [`mul!`](@ref) より下位の抽象化レイヤーです。独自のストレージ型を提供するパッケージでは、5 引数の `mul!` ではなく、このメソッドシグネチャをオーバーロードすることを推奨します。

!!! compat "Julia 1.13"
    このメソッドの使用には Julia 1.13 以降が必要です。また、同じシグネチャを持つ非公開の `generic_matvecmul!` メソッドに代わるものです。
