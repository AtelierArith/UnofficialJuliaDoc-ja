```julia
\(A, B)
```

多項式アルゴリズムによる行列除算。入力行列 `A` と `B` に対して、結果 `X` は、`A` が正方行列の場合、`A*X == B` となります。使用されるソルバーは、`A` の構造によって異なります。`A` が上三角行列、下三角行列、または対角行列の場合、`A` の因子分解は不要で、前進代入または後退代入によって連立方程式を解きます。三角行列でない正方行列には、LU分解を使用します。

長方形行列 `A` の場合、結果は、`A` のピボット付きQR分解と、R因子に基づく `A` のランク推定によって計算される、最小ノルム最小二乗解です。

`A` が疎行列の場合も、同様の多項式アルゴリズムを使用します。不定値行列では、`LDLt` 分解の数値分解時にピボット選択を行わないため、行列が可逆であっても処理に失敗することがあります。

関連項目: [`factorize`](@ref)、[`pinv`](@ref)。

# Examples

```jldoctest
julia> A = [1 0; 1 -2]; B = [32; -4];

julia> X = A \ B
2-element Vector{Float64}:
 32.0
 18.0

julia> A * X == B
true
```
