```julia
DateFormat(format::AbstractString, locale="english")
```

日付文字列の解析や、日付オブジェクトの文字列への整形に使用できる日付書式オブジェクトを構築します。`format` 文字列の構築には、次の文字コードを使用できます。

| コード        | 一致する値     | 説明                                           |
|:---------- |:--------- |:-------------------------------------------- |
| `Y`        | 1996, 96  | それぞれ 1996 年、0096 年を返します                      |
| `y`        | 1996, 96  | `parse` では `Y` と同じですが、`format` では余分な桁を切り捨てます |
| `m`        | 1, 01     | 1 桁または 2 桁の月に一致します                           |
| `u`        | Jan       | `locale` キーワードに従って、月名の略称に一致します               |
| `U`        | January   | `locale` キーワードに従って、月名の正式名称に一致します             |
| `d`        | 1, 01     | 1 桁または 2 桁の日に一致します                           |
| `H`        | 00        | 時（24 時間制）に一致します                              |
| `I`        | 00        | 時を 12 時間制で出力するために使用します                       |
| `M`        | 00        | 分に一致します                                      |
| `S`        | 00        | 秒に一致します                                      |
| `s`        | .500      | ミリ秒に一致します                                    |
| `e`        | Mon, Tues | 曜日名の略称に一致します                                 |
| `E`        | Monday    | 曜日名の正式名称に一致します                               |
| `p`        | AM        | AM/PM に一致します（大文字と小文字を区別しません）                 |
| `yyyymmdd` | 19960101  | 固定幅の年、月、日に一致します                              |

上記以外の文字は、通常、日付と時刻の各フィールドの区切り文字として扱われます。たとえば、`dt` 文字列が "1996-01-15T00:00:00.0" の場合、`format` 文字列は "y-m-dTH:M:S.s" のようになります。コードとして使われる文字を区切り文字として使用するには、バックスラッシュでエスケープします。日付 "1995y01m" の書式は "y\ym\m" となります。

12:00AM は 00:00（真夜中）に、12:00PM は 12:00（正午）に対応することに注意してください。`p` 指定子を含む時刻を解析する場合、時の指定は `H` と `I` のどちらでも 12 時間制として解釈されるため、`I` コードは主に出力時に役立ちます。

DateFormat オブジェクトの作成にはコストがかかります。可能な限り、一度作成したものを繰り返し使用するか、[`dateformat""`](@ref @dateformat_str) 文字列マクロを試してください。このマクロを使用すると、マクロ展開時に DateFormat オブジェクトが一度だけ作成され、以降は再利用されます。また、後述する [pre-defined formatters](@ref Common-Date-Formatters) もいくつか用意されています。

DateFormat オブジェクトを使用して Date 文字列を解析する方法については [`DateTime`](@ref) を、書き出す方法については [`format`](@ref) を参照してください。
