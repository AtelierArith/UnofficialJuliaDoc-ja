```julia
format(dt::TimeType, format::AbstractString; locale="english")::AbstractString
```

`TimeType` オブジェクトを使い、指定された `format` を適用して文字列を構築します。以下の文字コードを使って `format` 文字列を構築できます。

| コード | 例        | 説明                       |
|:--- |:-------- |:------------------------ |
| `y` | 6        | 固定幅の数値の年                 |
| `Y` | 1996     | 最小幅の数値の年                 |
| `m` | 1, 12    | 最小幅の数値の月                 |
| `u` | Jan      | `locale` に従った3文字の月名      |
| `U` | January  | `locale` キーワードに従った月の正式名称 |
| `d` | 1, 31    | 最小幅の日                    |
| `H` | 0, 23    | 最小幅の時（24時間制）             |
| `M` | 0, 59    | 最小幅の分                    |
| `S` | 0, 59    | 最小幅の秒                    |
| `s` | 000, 500 | 最小幅3のミリ秒                 |
| `e` | Mon, Tue | 曜日の略称                    |
| `E` | Monday   | 曜日の正式名称                  |

コード文字が連続する数によって、コードの幅が決まります。`yyyy-mm` という形式では、コード `y` の幅は4、`m` の幅は2になります。数値を出力するコードには、固定幅または最小幅のモードがあります。固定幅モードでは、値が指定幅より短い場合は左側をゼロで埋め、長い場合は切り詰めます。最小幅モードも固定幅モードと同様ですが、指定幅を超える値を切り詰めません。

`format` を作成するときは、コード以外の任意の文字を区切り文字として使用できます。たとえば、文字列 "1996-01-15T00:00:00" を生成するには、`format`: "yyyy-mm-ddTHH:MM:SS" を使用します。コード文字をリテラルとして使う必要がある場合は、エスケープ文字のバックスラッシュを使用できます。文字列 "1996y01m" は、書式 raw"yyyy\ymm\m" で生成できます。
