```julia
Fix{N}(f, x)
```

関数 `f` の一部適用版を表す型です。引数 `x` を位置 `N::Int` に固定します。つまり、`Fix{3}(f, x)` は `(y1, y2, y3...; kws...) -> f(y1, y2, x, y3...; kws...)` と同様に動作します。

!!! compat "Julia 1.12"
    この汎用機能を使うには Julia 1.12 以降が必要ですが、`Fix1` と `Fix2` はそれ以前のバージョンでも利用できます。


!!! note
    複数の `Fix` を入れ子にする場合、`Fix{N}` における `N` は、対象関数の引数全体に対する絶対的な順序ではなく、現在利用可能な引数に対する相対的な順序であることに注意してください。たとえば、`Fix{1}(Fix{2}(f, 4), 4)` は第1引数と第2引数を固定し、`Fix{2}(Fix{1}(f, 4), 4)` は第1引数と第3引数を固定します。
