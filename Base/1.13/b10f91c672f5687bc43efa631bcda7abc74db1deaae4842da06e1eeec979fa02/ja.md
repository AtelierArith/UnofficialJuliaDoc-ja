```julia
copy!(dst, src) -> dst
```

`src` の内容を `dst` にインプレースで [`copy`](@ref) します。このとき、`dst` に既存の要素があれば破棄されます。`dst` と `src` が同じ型であれば、呼び出し後も `dst == src` が成り立ちます。`dst` と `src` がベクトル型の場合、オフセットが等しくなければなりません。`dst` と `src` が多次元配列の場合、[`axes`](@ref) が等しくなければなりません。

!!! warning
    変更対象の引数が、ほかのいずれかの引数とメモリを共有している場合、予期しない動作になることがあります。


関連項目: [`copyto!`](@ref)。

!!! note
    ベクトル型を操作する際、`dst` と `src` の長さが異なる場合、`copy` の前に `dst` のサイズが `length(src)` に変更されます。


!!! compat "Julia 1.1"
    このメソッドを使用するには Julia 1.1 以降が必要です。Julia 1.0 では、このメソッドは `Future` 標準ライブラリの `Future.copy!` として利用できます。
