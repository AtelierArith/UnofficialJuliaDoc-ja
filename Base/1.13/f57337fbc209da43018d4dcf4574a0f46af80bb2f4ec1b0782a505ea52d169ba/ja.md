```julia
ntuple(f, ::Val{N})
```

長さが`N`のタプルを作成し、各要素を`f(i)`として計算します。ここで、`i`はその要素のインデックスです。`Val(N)`引数を渡すことで、長さを整数で指定するバージョンよりも、このバージョンのntupleのほうが効率的なコードを生成できる場合があります。ただし、`N`をコンパイル時に決定できない場合は、`ntuple(f, Val(N))`よりも`ntuple(f, N)`が適しています。

# Examples

```jldoctest
julia> ntuple(i -> 2*i, Val(4))
(2, 4, 6, 8)
```
