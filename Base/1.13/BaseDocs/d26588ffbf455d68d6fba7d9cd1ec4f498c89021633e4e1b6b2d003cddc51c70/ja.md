```julia
Symbol
```

パースされた Julia コード（AST）で識別子を表すために使われるオブジェクトの型です。また、エンティティを識別する名前やラベル（たとえば辞書のキー）として使われることもよくあります。`Symbol` は、`:` クォート演算子を使って入力できます。

```jldoctest
julia> :name
:name

julia> typeof(:name)
Symbol

julia> x = 42
42

julia> eval(:x)
42
```

`Symbol` は、コンストラクター `Symbol(x...)` を呼び出すことで、文字列やその他の値から作成することもできます。

`Symbol` は不変であり、同じ名前を持つすべての `Symbol` に対して、実装では同じオブジェクトが再利用されます。

文字列とは異なり、`Symbol` は「アトミック」または「スカラー」なエンティティであり、文字単位の反復処理には対応していません。
