```julia
primitive type
```

`primitive type`は、データがビット列のみで構成される具象型を宣言します。プリミティブ型の代表例として、整数や浮動小数点数があります。組み込みプリミティブ型の宣言例をいくつか示します。

```julia
primitive type Char 32 end
primitive type Bool <: Integer 8 end
```

型名の後の数値は、その型に必要な記憶領域のビット数を示します。現在サポートされているのは、8ビットの倍数のサイズのみです。[`Bool`](@ref)宣言は、プリミティブ型を任意でスーパータイプのサブタイプとして宣言する方法を示しています。
