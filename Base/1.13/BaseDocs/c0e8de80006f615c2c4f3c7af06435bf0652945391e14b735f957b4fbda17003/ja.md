```julia
*(x, y...)
```

乗算演算子。

中置演算子 `x*y*z*...` は、すべての引数を使ってこの関数を呼び出します。つまり、`*(x, y, z, ...)` です。デフォルトでは、左から順に `(x*y) * z * ...` を呼び出します。

`2pi` のような隣接記法も `*(2, pi)` を呼び出します。この演算は、リテラル `*` より優先順位が高いことに注意してください。また、「0x...」の隣接記法（整数の 0 と、名前が `x` で始まる変数の積）は、符号なし整数リテラルと衝突するため使用できません。`0x01 isa UInt8`

大きな数を乗算すると、デフォルトの `Int` を含む、ほとんどの整数型でオーバーフローが発生する可能性があります。

# Examples

```jldoctest
julia> 2 * 7 * 8
112

julia> *(2, 7, 8)
112

julia> [2 0; 0 3] * [1, 10]  # matrix * vector
2-element Vector{Int64}:
  2
 30

julia> 1/2pi, 1/2*pi  # juxtaposition has higher precedence
(0.15915494309189535, 1.5707963267948966)

julia> x = [1, 2]; x'x  # adjoint vector * vector
5
```
