```julia
+(x, y...)
```

加算演算子。

中置演算子 `x+y+z+...` は、すべての引数を使ってこの関数を呼び出します。つまり、`+(x, y, z, ...)` です。デフォルトでは、左から順に `(x+y) + z + ...` を呼び出します。

大きな数を加算すると、デフォルトの `Int` を含むほとんどの整数型でオーバーフローが発生する可能性があることに注意してください。

# Examples

```jldoctest
julia> 1 + 20 + 4
25

julia> +(1, 20, 4)
25

julia> [1,2] + [3,4]
2-element Vector{Int64}:
 4
 6

julia> typemax(Int) + 1 < 0
true
```
