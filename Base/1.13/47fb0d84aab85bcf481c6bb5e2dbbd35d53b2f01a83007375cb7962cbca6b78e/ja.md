```julia
prod(itr; [init])
```

コレクションのすべての要素の積を返します。

システムワードサイズ未満の符号付き整数の場合、戻り値の型は`Int`です。システムワードサイズ未満の符号なし整数の場合は`UInt`です。それ以外の引数では、すべての引数が昇格される共通の戻り値の型が決定されます。

空の`itr`に対して返される値は、`init`で指定できます。空でないコレクションでは`init`が使われるかどうかは未規定のため、この値は乗法単位元（つまり1）でなければなりません。

!!! compat "Julia 1.6"
    キーワード引数`init`を使用するには、Julia 1.6以降が必要です。


関連項目: [`reduce`](@ref)、[`cumprod`](@ref)、[`any`](@ref)。

# Examples

```jldoctest
julia> prod(1:5)
120

julia> prod(1:5; init = 1.0)
120.0
```
