```julia
mod2pi(x)
```

`2π`で割った余りを、``[0,2π)``の範囲で返します。

この関数は、数値的に正確な`2π`で割った余りを浮動小数点数で表現して計算します。そのため、`x`を浮動小数点数`2π`で割った余りを計算する`mod(x,2π)`とは、厳密には異なります。

!!! note
    入力値の形式によっては、2πに最も近い表現可能な値が2πより小さくなることがあります。たとえば、式`mod2pi(2π)`は`0`を返しません。中間値`2*π`が`Float64`であり、`2*Float64(π) < 2*big(π)`だからです。この動作をより細かく制御する方法については、[`rem2pi`](@ref)を参照してください。


# Examples

```jldoctest
julia> mod2pi(9*pi/4)
0.7853981633974481
```
