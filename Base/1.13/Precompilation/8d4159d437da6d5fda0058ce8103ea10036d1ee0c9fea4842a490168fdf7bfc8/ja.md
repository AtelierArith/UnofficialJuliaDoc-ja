```julia
precompilepkgs(pkgs; kwargs...)
```

パッケージとその依存関係をプリコンパイルします。並列コンパイル、進捗状況の追跡、さまざまなコンパイル設定に対応しています。

`pkgs::Union{Vector{String}, Vector{PkgId}}`: プリコンパイルするパッケージ。空の場合（デフォルト）は、プロジェクトのすべての依存関係をプリコンパイルします。指定した場合は、指定されたパッケージとその依存関係のみをプリコンパイルします（`manifest=true`の場合を除く）。

!!! note
    最上位の依存関係をプリコンパイルする場合にのみエラーがスローされます。指定されたシステムでは、マニフェストに記載されたすべての依存関係が最上位の依存関係によって読み込まれるとは限らないためです。kwarg `strict` に `true` を設定すると、この動作を変更し、すべての依存関係のエラーをスローできます。


# Keyword Arguments

  * `internal_call::Bool`: 外部（例: Pkg）からの自動プリコンパイル呼び出しであることを示します。このパラメーターは使用しないでください。
  * `strict::Bool`: エラー報告の範囲を制御します。`false`（デフォルト）の場合、プロジェクトの直接の依存関係についてのみエラーを報告します。`manifest=true`の場合にのみ関係します。
  * `warn_loaded::Bool`: `true`（デフォルト）の場合、プリコンパイル済みだが異なるバージョンですでに読み込まれているパッケージを確認し、警告します。新たにプリコンパイルされたバージョンを使うにはJuliaを再起動する必要があることを示す警告を表示します。
  * `timing::Bool`: `true`（デフォルトではない）の場合、コンパイルに成功した可能性がある場合に限り、各パッケージのコンパイル時間を表示します。見やすい進捗バーの表示は無効になり、時間はシンプルなテキスト形式で表示されます。
  * `_from_loading::Bool`: 呼び出し元がパッケージ読み込みシステムであることを示す内部フラグです。`true`（デフォルトではない）の場合、パッケージが見つからなくても例外をスローせずに早期リターンします。対話セッションでない場合は進捗メッセージを抑制し、現在の環境外のパッケージを直列プリコンパイルジョブとして追加できるようにします。また、LOADING_CACHEの初期化をスキップし、キャッシュファイルのロック動作を変更します。
  * `configs::Union{Config,Vector{Config}}`: 使用するコンパイル設定。各Configは、コマンドフラグとキャッシュフラグを指定する`Pair{Cmd, Base.CacheFlags}`です。複数の設定を指定すると、各パッケージは設定ごとにプリコンパイルされます。
  * `io::IO`: 進捗メッセージ、警告、エラーの出力先ストリーム。リダイレクトできます（例: 非対話モードで読み込み時に呼び出す場合は`devnull`）。
  * `fancyprint::Bool`: 出力形式を制御します。`true`の場合、スピナー付きのアニメーション進捗バーを表示します。`false`の場合は、代わりに`timing`モードを有効にします。`timing=true`の場合、または非対話モードで読み込み時に呼び出された場合は、自動的に無効になります。
  * `manifest::Bool`: プリコンパイルするパッケージの範囲を制御します。`false`（デフォルト）の場合、`pkgs`で指定されたパッケージとその依存関係のみをプリコンパイルします。`true`の場合、マニフェスト内のすべてのパッケージをプリコンパイルします（ワークスペースモード）。通常、Pkgがワークスペースのプリコンパイルを要求する際に使用されます。
  * `ignore_loaded::Bool`: 読み込み済みパッケージがキャッシュの鮮度チェックに影響するかどうかを制御します。`false`（デフォルトではない）の場合、キャッシュファイルが最新かどうかを判定する際に、読み込み済みパッケージのバージョンを考慮します。

# Return

  * `Vector{String}`: 要求されたパッケージのキャッシュファイルへのパス。
  * `Nothing`: プリコンパイルをスキップする必要がある

# Notes

  * 循環依存関係にあるパッケージは、警告を出してスキップされます。
  * `__precompile__(false)`を持つパッケージは、セッションごとに同じ処理が繰り返されないよう、読み込み時にはスキップされます。
  * 並列コンパイルは、環境変数`JULIA_NUM_PRECOMPILE_TASKS`で制御されます（デフォルトはCPU_THREADS + 1、最大16。Windowsでは半分になります）。
  * 拡張機能は、そのすべてのトリガーが環境内で利用可能な場合にプリコンパイルされます。
