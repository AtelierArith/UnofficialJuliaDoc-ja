```julia
@r_str -> Regex
```

補間やエスケープ処理を行わずに正規表現を作成します。たとえば `r"^[a-z]*$"` のように記述します（ただし、引用符 `"` はエスケープする必要があります）。終了引用符の後に1つ以上のフラグを指定すると、正規表現の動作を変更できます。

  * `i` は、大文字と小文字を区別しないマッチングを有効にします。
  * `m` は、`^` と `$` が文字列全体ではなく、各行の先頭と末尾にマッチするようにします。
  * `s` は、`.` 修飾子が改行にもマッチするようにします。
  * `x` は「フリースペースモード」を有効にします。このモードでは、エスケープされていない空白は正規表現のトークン間で無視され、`\` でエスケープされた空白は無視されません。また、正規表現中の `#` はコメントの開始として扱われ、行末まで無視されます。
  * `a` は ASCII モードを有効にします（`UTF` モードと `UCP` モードは無効になります）。デフォルトでは、`\B`、`\b`、`\D`、`\d`、`\S`、`\s`、`\W`、`\w` などは、Unicode の文字プロパティに基づいてマッチします。このオプションを指定すると、これらのシーケンスは ASCII 文字にのみマッチします。`\u` も同様に、指定された文字値を UTF-8 にエンコードしようとせず、単一バイトとして直接出力します。重要な点として、このオプションを使うと、不正な UTF-8 文字列にもマッチできます。マッチャーと対象を文字エンコーディングではなく、単純なバイト列（ISO/IEC 8859-1 / Latin-1 のバイト列と同様）として扱うためです。この場合、このオプションは `s` と組み合わせて使われることがよくあります。パターンの先頭に (*UCP) または (*UTF) を指定すると、このオプションをさらに細かく調整できます。

補間が必要な場合は、[`Regex`](@ref) を参照してください。

# Examples

```jldoctest
julia> match(r"a+.*b+.*?d$"ism, "Goodbye,\nOh, angry,\nBad world\n")
RegexMatch("angry,\nBad world")
```

この正規表現では、最初の3つのフラグが有効になっています。
