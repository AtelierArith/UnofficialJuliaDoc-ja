```julia
unsafe_swap!(p::Ptr{T}, x, [order::Symbol])
```

これらの関数は、メモリアドレスの取得と設定を同時にアトミックに実行します。ハードウェアが対応している場合は、適切なハードウェア命令に最適化されます。対応していない場合、実行は次のようになります。

```julia
y = unsafe_load(p)
unsafe_store!(p, x)
return y
```

この関数の接頭辞 `unsafe` は、ポインター `p` が有効かどうかの検証を行わないことを示します。C と同様に、この関数の呼び出し中に参照先のメモリが解放されたり、ガベージコレクションされたりしないようにする責任はプログラマーにあります。誤った使い方をすると、プログラムがセグフォルトを起こす可能性があります。

!!! compat "Julia 1.10"
    この関数を使用するには、Julia 1.10 以降が必要です。
