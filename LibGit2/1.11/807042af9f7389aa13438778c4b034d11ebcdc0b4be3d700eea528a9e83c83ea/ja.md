LibGit2.CloneOptions

[`git_clone_options`](https://libgit2.org/libgit2/#HEAD/type/git_clone_options) 構造体に一致します。

各フィールドの意味は次のとおりです。

  * `version`: 後で変更される場合に備えた、使用中の構造体のバージョン。現時点では常に `1` です。
  * `checkout_opts`: クローンの一環としてリモートをチェックアウトする際のオプション。
  * `fetch_opts`: クローンの一環として、チェックアウト前にリモートをフェッチする際のオプション。
  * `bare`: `0` の場合、リモートリポジトリ全体をクローンします。ゼロ以外の場合はベアクローンを実行します。ベアクローンでは、リポジトリ内にソースファイルのローカルコピーがなく、[`gitdir`](@ref) と [`workdir`](@ref) は同じになります。
  * `localclone`: ローカルのオブジェクトデータベースをクローンするか、フェッチを行うかを指定するフラグ。デフォルトでは git に判断を任せます。ローカルクローンでは git 対応のトランスポートを使用しませんが、`file://` で始まる URL では使用します。
  * `checkout_branch`: チェックアウトするブランチ名。空文字列の場合、リモートのデフォルトブランチをチェックアウトします。
  * `repository_cb`: クローン先となる *新しい* リポジトリを作成するために使用する、任意のコールバック。
  * `repository_cb_payload`: リポジトリコールバックに渡すペイロード。
  * `remote_cb`: クローン元となる [`GitRemote`](@ref) を作成するために、クローンの実行前に使用する任意のコールバック。
  * `remote_cb_payload`: リモートコールバックに渡すペイロード。
