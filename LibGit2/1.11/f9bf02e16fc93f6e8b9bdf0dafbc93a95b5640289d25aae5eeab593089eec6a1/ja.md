```julia
LibGit2.CheckoutOptions
```

[`git_checkout_options`](https://libgit2.org/libgit2/#HEAD/type/git_checkout_options) 構造体に対応します。

各フィールドの意味は次のとおりです。

  * `version`: 後で変更される場合に備えた、使用中の構造体のバージョン。現時点では常に `1` です。
  * `checkout_strategy`: 競合の処理方法と、チェックアウトを強制するか、欠落ファイルを再作成するかを指定します。
  * `disable_filters`: 0 以外の場合、CLRF（ファイルの改行コードを UNIX と DOS の間で変換するフィルターなど）を適用しません。
  * `dir_mode`: チェックアウトに関係するディレクトリの読み取り／書き込み／アクセスモード。デフォルトは `0755` です。
  * `file_mode`: チェックアウトに関係するファイルの読み取り／書き込み／アクセスモード。デフォルトは、blob に応じて `0755` または `0644` です。
  * `file_open_flags`: チェックアウト中にファイルを開く際に使用するビットフラグ。
  * `notify_flags`: ユーザーに通知する競合の種類を指定するフラグ。
  * `notify_cb`: チェックアウトで競合が発生した場合にユーザーへ通知する、任意のコールバック関数。この関数が 0 以外の値を返すと、チェックアウトはキャンセルされます。
  * `notify_payload`: 通知コールバック関数に渡すペイロード。
  * `progress_cb`: チェックアウトの進行状況を表示する、任意のコールバック関数。
  * `progress_payload`: 進行状況コールバックに渡すペイロード。
  * `paths`: 空でない場合、チェックアウト中に検索するパスを指定します。空の場合、リポジトリ内のすべてのファイルがチェックアウト対象になります。
  * `baseline`: [`workdir`](@ref) の想定内容。[`GitTree`](@ref) へのポインター（またはそのポインター）に格納されます。デフォルトは HEAD におけるツリーの状態です。
  * `baseline_index`: [`workdir`](@ref) の想定内容。`GitIndex` へのポインター（またはそのポインター）に格納されます。デフォルトは HEAD におけるインデックスの状態です。
  * `target_directory`: 空でない場合、`workdir` ではなく、このディレクトリにチェックアウトします。
  * `ancestor_label`: 競合が発生した場合、共通祖先側の名前。
  * `our_label`: 競合が発生した場合、「ours」側の名前。
  * `their_label`: 競合が発生した場合、「theirs」側の名前。
  * `perfdata_cb`: パフォーマンスデータを表示する、任意のコールバック関数。
  * `perfdata_payload`: パフォーマンスコールバックに渡すペイロード。
