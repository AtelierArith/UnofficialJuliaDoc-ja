# [Punctuation](@id man-punctuation)

数学記号と関数についての詳しいドキュメントは[here](@ref math-ops)にあります。

| 記号                | 意味                                                                                                                                                     |
|:----------------- |:------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `@`               | アットマークは[macro](@ref man-macros)の呼び出しを示します。引数リストを続けることもできます                                                                                             |
| [`!`](@ref)       | 感嘆符は、論理否定（「not」）を表す前置演算子です                                                                                                                             |
| `a!`              | 慣例として、名前が感嘆符で終わる関数は、1つ以上の引数を変更します                                                                                                                      |
| `#`               | 番号記号（ハッシュ記号、またはポンド記号）は、1行コメントの開始を示します                                                                                                                  |
| `#=`              | 等号が続く場合は複数行コメントの開始を示します（複数行コメントは入れ子にできます）                                                                                                              |
| `=#`              | 複数行コメントを終了するには、番号記号の直前に等号を置きます                                                                                                                         |
| `$`               | ドル記号は、[string](@ref string-interpolation)および[expression](@ref man-expression-interpolation)の補間に使われます                                                   |
| [`%`](@ref rem)   | パーセント記号は剰余演算子です                                                                                                                                        |
| [`^`](@ref)       | キャレットはべき乗演算子です                                                                                                                                         |
| [`&`](@ref)       | 単一のアンパサンドはビット単位のANDです                                                                                                                                  |
| [`&&`](@ref)      | 二重アンパサンドは短絡評価を行う論理ANDです                                                                                                                                |
| [`\|`](@ref)      | 単一のパイプ文字はビット単位のORです                                                                                                                                    |
| [`\|\|`](@ref)    | 二重パイプ文字は短絡評価を行う論理ORです                                                                                                                                  |
| [`⊻`](@ref xor)   | UnicodeのXOR文字はビット単位の排他的ORです                                                                                                                            |
| [`~`](@ref)       | チルダはビット単位のNOT演算子です                                                                                                                                     |
| `'`               | 末尾のアポストロフィは[`adjoint`](@ref)（複素転置）演算子Aᴴです                                                                                                              |
| [`*`](@ref)       | アスタリスクは、行列乗算や[string concatenation](@ref man-concatenation)を含む乗算に使われます                                                                                 |
| [`/`](@ref)       | スラッシュは、左側の引数を右側の引数で割ります                                                                                                                                |
| [`//`](@ref)      | 二重スラッシュは、厳密な有理数除算を行います                                                                                                                                 |
| [`\`](@ref)       | バックスラッシュ演算子は、右側の引数を左側の引数で割ります。行列方程式を解く際によく使われます                                                                                                        |
| `()`              | 引数なしの括弧は、空の[`Tuple`](@ref)を構築します                                                                                                                       |
| `(a,...)`         | カンマ区切りの引数を括弧で囲むと、それらの引数を含むタプルを構築します                                                                                                                    |
| `(a=1,...)`       | カンマ区切りの代入を括弧で囲むと、[`NamedTuple`](@ref)を構築します                                                                                                            |
| `(x;y)`           | 括弧は、セミコロンで区切られた1つ以上の式をまとめるためにも使えます                                                                                                                     |
| `a[]`             | [array indexing](@ref man-array-indexing)（[`getindex`](@ref)または[`setindex!`](@ref)の呼び出し）                                                               |
| `[,]`             | [vector literal constructor](@ref man-array-literals)（[`vect`](@ref Base.vect)の呼び出し）                                                                   |
| `[;]`             | [vertical concatenation](@ref man-array-concatenation)（[`vcat`](@ref)または[`hvcat`](@ref)の呼び出し）                                                          |
| `[    ]`          | 式をスペースで区切ると、[horizontal concatenation](@ref man-concatenation)（[`hcat`](@ref)または[`hvcat`](@ref)の呼び出し）になります                                             |
| `T{ }`            | 型の後に波括弧を付けると、その型の[parameters](@ref Parametric-Types)を表します                                                                                              |
| `{}`              | 波括弧は、関数宣言内で複数の[`where`](@ref)式をまとめるためにも使えます                                                                                                            |
| `;`               | セミコロンは、文の区切り、関数宣言や呼び出しにおけるキーワード引数リストの開始、または配列リテラルを縦方向に連結する際の区切りに使われます                                                                                  |
| `,`               | カンマは、関数の引数、タプルの要素、または配列の要素を区切ります                                                                                                                       |
| `?`               | 疑問符は三項条件演算子の区切りです（使用例：`conditional ? if_true : if_false`）                                                                                              |
| `" "`             | 二重引用符1つで[`String`](@ref)リテラルを囲みます                                                                                                                      |
| `""" """`         | 二重引用符3つで文字列リテラルを囲みます。この形式では`"`を含めることができ、先頭のインデントは無視されます                                                                                                |
| `' '`             | アポストロフィ1つで[`Char`](@ref)（文字）リテラルを囲みます                                                                                                                  |
| ``` ` ` ```       | バッククォートで[external process](@ref Running-External-Programs)（[`Cmd`](@ref)）リテラルを囲みます                                                                     |
| `A...`            | ピリオド3つは後置演算子です。関数呼び出しの引数を展開して複数の引数にしたり、可変長引数関数を宣言して複数の引数を1つのタプルにまとめたりします                                                                               |
| `a.b`             | ピリオド1つは、オブジェクトやモジュールの名前付きフィールドにアクセスします（[`getproperty`](@ref Base.getproperty)または[`setproperty!`](@ref Base.setproperty!)の呼び出し）                         |
| `f.()`            | ピリオドは括弧（`f.(...)`など）の前や、中置演算子（`.+`など）の前に置くこともでき、その場合は関数を要素ごとに適用します（[`broadcast`](@ref)の呼び出し）                                                           |
| `a:b`             | コロン（[`:`](@ref)）を二項中置演算子として使うと、`a`から`b`まで（両端を含む）、刻み幅`1`の範囲を構築します                                                                                       |
| `a:s:b`           | コロン（[`:`](@ref)）を三項中置演算子として使うと、`a`から`b`まで（両端を含む）、刻み幅`s`の範囲を構築します                                                                                       |
| `:`               | 単独で使うと、[`Colon`](@ref)は次元内のすべてのインデックスを表します。[indexing](@ref man-array-indexing)と組み合わせて使われることがよくあります                                                     |
| `::`              | 二重コロンは、文脈に応じて型注釈または[`typeassert`](@ref)を表します。関数の引数を宣言する際によく使われます                                                                                       |
| `:( )`            | 引用された式                                                                                                                                                 |
| `:a`              | [`Symbol`](@ref) a                                                                                                                                     |
| [`<:`](@ref)      | サブタイプ演算子                                                                                                                                               |
| [`>:`](@ref)      | スーパータイプ演算子（サブタイプ演算子の逆）                                                                                                                                 |
| `=`               | 等号1つは[assignment](@ref man-variables)です                                                                                                                |
| [`==`](@ref)      | 等号2つは値の等価性を比較します                                                                                                                                       |
| [`===`](@ref)     | 等号3つはプログラム上の同一性を比較します                                                                                                                                  |
| [`=>`](@ref Pair) | 等号を使った右矢印は[`Pair`](@ref)を定義します。通常、[dictionaries](@ref Dictionaries)に値を設定するために使われます                                                                     |
| `->`              | ハイフンを使った右矢印は、1行で[anonymous function](@ref man-anonymous-functions)を定義します                                                                               |
| [`\|>`](@ref)     | パイプ演算子は、左側の引数の出力を右側の引数の入力に渡します。通常、右側には[function](@ref Function-composition-and-piping)を指定します                                                           |
| `∘`               | 関数合成演算子（\circ{tab}と入力）は、2つの関数を1つの大きな[function](@ref Function-composition-and-piping)のように結合します                                                          |
| `_`               | アンダースコアには、保存されない値を代入できます。[multiple return values](@ref destructuring-assignment)を無視したり、繰り返しの[comprehensions](@ref man-comprehensions)を作成したりする際によく使われます |
