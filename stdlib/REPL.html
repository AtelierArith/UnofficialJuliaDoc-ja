The Julia REPL

Juliaには、julia実行ファイルに組み込まれた、機能豊富な対話型コマンドラインREPL（read-eval-print loop）が付属しています。Juliaの文をすばやく簡単に評価できるだけでなく、検索可能な履歴、タブ補完、便利なキーバインド、専用のヘルプモードとシェルモードも備えています。引数を指定せずにjuliaを呼び出すか、実行ファイルをダブルクリックするだけでREPLを起動できます。

$ julia

               _
   _       _ _(_)_     |  Documentation: https://docs.julialang.org
  (_)     | (_) (_)    |
   _ _   _| |_  __ _   |  Type "?" for help, "]?" for Pkg help.
  | | | | | | |/ _` |  |
  | | |_| | | | (_| |  |  Version 1.13.3 (2026-10-25)
 _/ |\__'_|_|_|\__'_|  |  HEAD/67ac47b* (fork: 1 commits, 12 days)
|__/                   |


julia>

対話セッションを終了するには、^D（空行でControlキーとdキーを同時に押す）と入力するか、exit()と入力してReturnキーまたはEnterキーを押します。REPLがバナーとjulia>プロンプトを表示します。

The different prompt modes

The Julian mode

REPLには、主に5つの動作モードがあります。最も一般的なのはJuliaプロンプトで、デフォルトのモードです。新しい行は通常、julia>で始まります。ここにJuliaの式を入力します。式を入力し終えてReturnキーまたはEnterキーを押すと、その式が評価され、最後の式の結果が表示されます。

julia> string(1 + 2)
"3"

対話的な作業に便利な機能もいくつかあります。REPLは結果を表示するだけでなく、その結果を変数ansにも束縛します。行末にセミコロンを付けると、結果の表示を抑制できます。

julia> string(3 * 4);

julia> ans
"12"

Juliaモードでは、「プロンプト貼り付け」と呼ばれる機能が使えます。julia>で始まるテキストをREPLに貼り付けると、この機能が有効になります。この場合、julia>で始まる式（および他のREPLモードのプロンプトであるshell>、help?>、pkg>）だけが解析され、それ以外は削除されます。そのため、プロンプトや出力を取り除かなくても、REPLセッションからコピーしたテキストをまとめて貼り付けられます。この機能はデフォルトで有効ですが、REPL.enable_promptpaste(::Bool)でいつでも無効化または有効化できます。有効な場合は、この段落の上にあるコードブロックをそのままREPLに貼り付けて試せます。標準のWindowsコマンドプロンプトでは、貼り付けが行われたことを検出する機能に制限があるため、この機能は動作しません。

式の実行結果がnothingでない場合、REPLは特定のIOContextを指定してshow関数を使い、結果を表示します（display経由で指定されます。デフォルトではshow(io, MIME("text/plain"), ans)を呼び出し、さらにそのデフォルトはshow(io, ans)です）。特に、:limit属性はtrueに設定されます。showメソッドによっては、:compactのように、まだ設定されていない属性にデフォルト値が設定されることもあります。実験的な機能として、Base.active_repl.options.iocontext辞書を使い、REPLで使用する属性とその値を指定できます。たとえば、次のようにします。

julia> rand(2, 2)
2×2 Matrix{Float64}:
 0.8833    0.329197
 0.719708  0.59114

julia> show(IOContext(stdout, :compact => false), "text/plain", rand(2, 2))
 0.43540323669187075  0.15759787870609387
 0.2540832269192739   0.4597637838786053
julia> Base.active_repl.options.iocontext[:compact] = false;

julia> rand(2, 2)
2×2 Matrix{Float64}:
 0.2083967319174056  0.13330606013126012
 0.6244375177790158  0.9777957560761545

起動時にこの辞書の値を自動的に定義するには、たとえば~/.julia/config/startup.jlファイルでatreplinit関数を使います。

atreplinit() do repl
    repl.options.iocontext[:compact] = false
end

Help mode

カーソルが行頭にあるときに?と入力すると、プロンプトをヘルプモードに切り替えられます。ヘルプモードで入力した内容について、Juliaはヘルプやドキュメントの表示を試みます。

julia> ? # upon typing ?, the prompt changes (in place) to: help?>

help?> string
search: string String Cstring Cwstring RevString randstring bytestring SubString

  string(xs...)

  Create a string from any values using the print function.

マクロ、型、変数についても問い合わせることができます。

help?> @time
  @time

  A macro to execute an expression, printing the time it took to execute, the number of allocations,
  and the total number of bytes its execution caused to be allocated, before returning the value of the
  expression.

  See also @timev, @timed, @elapsed, and @allocated.

help?> Int32
search: Int32 UInt32

  Int32 <: Signed

  32-bit signed integer type.

文字列リテラルまたは正規表現リテラルを入力すると、aproposを使ってすべてのdocstringを検索できます。

help?> "aprop"
REPL.stripmd
Base.Docs.apropos

help?> r"ap..p"
Base.:∘
Base.shell_escape_posixly
Distributed.CachingPool
REPL.stripmd
Base.Docs.apropos

ヘルプモードでは、拡張docstringにもアクセスできます。たとえば、?Printではなく??Printと入力すると、ソースコードのドキュメントにある# Extended helpセクションが表示されます。

ヘルプモードを終了するには、行頭でBackspaceキーを押します。

Shell mode

ヘルプモードでドキュメントをすばやく参照できるのと同様に、システムシェルを使ってシステムコマンドを実行することもよくあります。行頭で?を入力するとヘルプモードに切り替わりますが、セミコロン（;）を入力するとシェルモードに切り替わります。シェルモードは、行頭でBackspaceキーを押すと終了できます。

julia> ; # upon typing ;, the prompt changes (in place) to: shell>

shell> echo hello
hello
Note

Windowsユーザーの場合、JuliaのシェルモードからWindowsのシェルコマンドを実行することはできません。そのため、次のコマンドは失敗します。

julia> ; # upon typing ;, the prompt changes (in place) to: shell>

shell> dir
ERROR: IOError: could not spawn `dir`: no such file or directory (ENOENT)
Stacktrace!
.......

ただし、次のようにすればPowerShellを利用できます。

julia> ; # upon typing ;, the prompt changes (in place) to: shell>

shell> powershell
Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.
PS C:\Users\elm>

また、dirコマンドを使えば、次のようにcmd.exeも利用できます。

julia> ; # upon typing ;, the prompt changes (in place) to: shell>

shell> cmd
Microsoft Windows [version 10.0.17763.973]
(c) 2018 Microsoft Corporation. All rights reserved.
C:\Users\elm>dir
 Volume in drive C has no label
 Volume Serial Number is 1643-0CD7
  Directory of C:\Users\elm

29/01/2020  22:15    <DIR>          .
29/01/2020  22:15    <DIR>          ..
02/02/2020  08:06    <DIR>          .atom

Pkg mode

パッケージマネージャーモードでは、パッケージの読み込みや更新に特化したコマンドを使えます。Julia REPLのプロンプトで]キーを押すとこのモードに入り、CTRL-Cまたは行頭でBackspaceキーを押すと終了します。このモードのプロンプトはpkg>です。専用のヘルプモードもあり、pkg>プロンプトの行頭で?を押すと入れます。パッケージマネージャーモードの詳細は、https://julialang.github.io/Pkg.jl/v1/で参照できるPkgマニュアルに記載されています。

History searching

上記のすべてのモードで、実行した行は検索可能な履歴ファイルに保存されます。過去の履歴を対話的に検索するには、^R（Controlキーとrキー）を押します。

対話型の履歴ビューアーが表示されます。検索文字列を入力すると履歴が絞り込まれ、Enterキーを押すと選択した履歴項目がREPLに挿入されます。履歴検索機能の詳しいヘルプは、REPLで特殊なクエリ?および??を使って参照できます。

Julia REPLで実行したコマンドはすべて~/.julia/logs/repl_history.jlに記録されます。記録には実行時のタイムスタンプと、そのときのREPLモードも含まれます。履歴検索機能はこのログファイルを読み込み、以前に実行したコマンドを検索します。複数のREPLから同時にこのファイルへ書き込むことができ、検索を開始するたびに最新の履歴が取得されます。Juliaの起動時に--history-file=noフラグを渡すと、このファイルの使用を無効にできます。

Customizing keybindings

REPL.setup_interfaceに辞書を渡すと、Julia REPLのキーバインドをユーザーの好みに合わせて自由にカスタマイズできます。この辞書のキーには文字または文字列を指定できます。キー'*'はデフォルトのアクションを表します。Controlキーと文字xの組み合わせは、"^x"で表します。Metaキーとxの組み合わせは"\\M-x"または"\ex"、Controlキーとxの組み合わせは"\\C-x"または"^x"と記述できます。カスタムキーマップの値には、入力を無視することを示すnothing、またはシグネチャ(PromptState, AbstractREPL, Char)を受け取る関数を指定します。REPL.setup_interface関数はREPLの初期化前に呼び出す必要があるため、atreplinitに処理を登録します。たとえば、上矢印キーと下矢印キーで、前方一致検索を使わずに履歴を移動できるようにするには、次のコードを~/.julia/config/startup.jlに記述します。

import REPL
import REPL.LineEdit

const mykeys = Dict{Any,Any}(
    # Up Arrow
    "\e[A" => (s,o...)->(LineEdit.edit_move_up(s) || LineEdit.history_prev(s, LineEdit.mode(s).hist)),
    # Down Arrow
    "\e[B" => (s,o...)->(LineEdit.edit_move_down(s) || LineEdit.history_next(s, LineEdit.mode(s).hist))
)

function customize_keys(repl)
    repl.interface = REPL.setup_interface(repl; extra_repl_keymap = mykeys)
end

atreplinit(customize_keys)

キー入力に対して利用できるアクションを確認するには、LineEdit.jlを参照してください。

Automatic bracket insertion

Julia REPLでは、開き括弧、丸括弧、中括弧、引用符を入力すると、対応する閉じ記号を自動挿入できます。

この機能が有効な場合、開き括弧(、{、または[を入力すると、対応する閉じ括弧)、}、または]が自動挿入され、カーソルはその間に置かれます。引用符（"、'、$`$）も同様です。その後、閉じ記号を入力すると、REPLは重複して挿入する代わりに、自動挿入された記号を飛び越えます。また、自動挿入の直後にBackspaceキーを押すと、開き記号と閉じ記号の両方が削除されます。

この機能を無効にするには、~/.julia/config/startup.jlファイルに次の設定を追加します。

atreplinit() do repl
    # Robust against older julia versions
    if hasfield(typeof(repl.options), :auto_insert_closing_bracket)
        repl.options.auto_insert_closing_bracket = false
    end
end

Tab completion

REPLのJuliaモード、pkgモード、ヘルプモードでは、関数名や型名の先頭数文字を入力してTabキーを押すと、一致する候補の一覧が表示されます。

julia> x[TAB]
julia> xor

場合によっては、曖昧さが生じる直前までしか補完されないことがあります。

julia> mapf[TAB]
julia> mapfold

その状態でもう一度Tabキーを押すと、補完候補の一覧が表示されます。

julia> mapfold[TAB]
mapfoldl mapfoldr

入力行の末尾でタブ補完の候補が1つに絞られ、2文字以上入力されている場合は、補完候補が薄い色でヒント表示されます。この機能はBase.active_repl.options.hint_tab_completes = falseで無効にするか、次の設定を

atreplinit() do repl
    if VERSION >= v"1.11.0-0"
        repl.options.hint_tab_completes = false
    end
end

~/.julia/config/startup.jlに追加して無効にできます。

Julia 1.11

タブ補完のヒント表示はJulia 1.11で追加されました。

REPLのほかの機能と同様、検索では大文字と小文字が区別されます。

julia> stri[TAB]
stride     strides     string      strip

julia> Stri[TAB]

 1

\hat              \hermitconjmatrix  \hkswarow          \hrectangle

Customizing Colors

JuliaとREPLで使われる色もカスタマイズできます。Juliaプロンプトの色を変更するには、ホームディレクトリに置く~/.julia/config/startup.jlファイルに、たとえば次の設定を追加します。

function customize_colors(repl)
    repl.prompt_color = Base.text_colors[:cyan]
end

atreplinit(customize_colors)

利用可能な色のキーは、REPLのヘルプモードでBase.text_colorsと入力すると確認できます。また、256色に対応した端末では、0から255までの整数を色のキーとして使えます。

ヘルプとシェルのプロンプト、入力テキスト、応答テキストの色も変更できます。上記のcustomize_colors関数で、replの適切なフィールドを設定します（順にhelp_color、shell_color、input_color、answer_color）。後者の2つについては、envcolorsフィールドもfalseに設定してください。

色としてBase.text_colors[:bold]を使うと、太字表示も適用できます。たとえば、応答を太字で表示するには、~/.julia/config/startup.jlに次の設定を使います。

function customize_colors(repl)
    repl.envcolors = false
    repl.answer_color = Base.text_colors[:bold]
end

atreplinit(customize_colors)

環境変数を設定すると、警告メッセージや情報メッセージの色も変更できます。たとえば、エラー、警告、情報メッセージをそれぞれマゼンタ、黄色、シアンで表示するには、~/.julia/config/startup.jlファイルに次の設定を追加します。

ENV["JULIA_ERROR_COLOR"] = :magenta
ENV["JULIA_WARN_COLOR"] = :yellow
ENV["JULIA_INFO_COLOR"] = :cyan

Numbered prompt

IPython REPLやMathematicaノートブックに似た、入力プロンプトに番号を付け、出力に接頭辞を付けるインターフェースも利用できます。これを有効にするには、REPL.numbered_prompt!()を呼び出します。起動時から有効にするには、次の設定を

atreplinit() do repl
    @eval import REPL
    if !isdefined(repl, :interface)
        repl.interface = REPL.setup_interface(repl)
    end
    REPL.numbered_prompt!(repl)
end

startup.jlファイルに追加します。番号付きプロンプトでは、変数Out[n]（nは整数）を使って、以前の結果を参照できます。

Out[1]: 8

In [2]: Out[1] + 5
Out[2]: 13

In [3]: Out
Out[3]: Dict{Int64, Any} with 2 entries:
  2 => 13
  1 => 8
Note

以前のREPL評価の出力はすべてOut変数に保存されます。そのため、配列などの大きなインメモリオブジェクトを多数返す場合は注意が必要です。Outに参照が残っている限り、それらのオブジェクトはガベージコレクションの対象になりません。Out内のオブジェクトへの参照を削除するには、empty!(Out)で履歴全体を消去するか、Out[n] = nothingで個別の項目を消去します。

TerminalMenus

TerminalMenusはJulia REPLのサブモジュールで、端末上に小さく控えめな対話型メニューを表示できます。

Examples

import REPL
using REPL.TerminalMenus

options = ["apple", "orange", "grape", "strawberry",
            "blueberry", "peach", "lemon", "lime"]

RadioMenu

RadioMenuでは、一覧から1つの選択肢を選べます。request関数は対話型メニューを表示し、選択された項目のインデックスを返します。ユーザーが「q」またはctrl-cを押すと、requestは-1を返します。

# `pagesize` is the number of items to be displayed at a time.
#  The UI will scroll if the number of options is greater
#   than the `pagesize`
menu = RadioMenu(options, pagesize=4)

# `request` displays the menu and returns the index after the
#   user has selected a choice
choice = request("Choose your favorite fruit:", menu)

if choice != -1
    println("Your favorite fruit is ", options[choice], "!")
else
    println("Menu canceled.")
end

出力：

Choose your favorite fruit:
^  grape
   strawberry
 > blueberry
v  peach
Your favorite fruit is blueberry!

MultiSelectMenu

MultiSelectMenuでは、一覧から複数の選択肢を選べます。

# here we use the default `pagesize` 10
menu = MultiSelectMenu(options)

# `request` returns a `Set` of selected indices
# if the menu us canceled (ctrl-c or q), return an empty set
choices = request("Select the fruits you like:", menu)

if length(choices) > 0
    println("You like the following fruits:")
    for i in choices
        println("  - ", options[i])
    end
else
    println("Menu canceled.")
end

出力：

[press: Enter=toggle, a=all, n=none, d=done, q=abort]
   [ ] apple
 > [X] orange
   [X] grape
   [ ] strawberry
   [ ] blueberry

   [ ] lemon
   [ ] lime

  - orange

Customization / Configuration

ConfiguredMenu subtypes

Julia 1.6以降では、メニューの設定にはコンストラクターを使う方法が推奨されています。たとえば、デフォルトの複数選択メニュー

julia> menu = MultiSelectMenu(options, pagesize=5);

julia> request(menu) # ASCII is used by default
[press: Enter=toggle, a=all, n=none, d=done, q=abort]
   [ ] apple
   [X] orange
   [ ] grape
 > [X] strawberry
v  [ ] blueberry

は、選択や移動にUnicode文字を使って次のように表示できます。

julia> menu = MultiSelectMenu(options, pagesize=5, charset=:unicode);

julia> request(menu)
[press: Enter=toggle, a=all, n=none, d=done, q=abort]
   ⬚ apple
   ✓ orange
   ⬚ grape
 → ✓ strawberry
↓  ⬚ blueberry

さらに細かい設定も可能です。

julia> menu = MultiSelectMenu(options, pagesize=5, charset=:unicode, checked="YEP!", unchecked="NOPE", cursor='⧐');

julia> request(menu)
julia> request(menu)
[press: Enter=toggle, a=all, n=none, d=done, q=abort]
   NOPE apple
   YEP! orange
   NOPE grape
 ⧐ YEP! strawberry
↓  NOPE blueberry

全体に適用されるcharsetオプションのほか、RadioMenuでは次のオプションを設定できます。

  • cursor::Char='>'|'→'：カーソルに使う文字
  • up_arrow::Char='^'|'↑'：上矢印に使う文字
  • down_arrow::Char='v'|'↓'：下矢印に使う文字
  • updown_arrow::Char='I'|'↕'：1行ページで上下矢印に使う文字
  • scroll_wrap::Bool=false：メニューの先頭または末尾で折り返すかどうか
  • ctrl_c_interrupt::Bool=true：falseの場合、^Cで空を返す。trueの場合、^CでInterruptException()をスローする

MultiSelectMenuでは、さらに次のオプションを設定できます。

  • checked::String="[X]"|"✓"：選択済み項目に使う文字列
  • unchecked::String="[ ]"|"⬚")：未選択項目に使う文字列

独自のメニュー型を作成することもできます。TerminalMenus.ConfiguredMenuから派生した型では、構築時にメニューオプションを設定します。

Legacy interface

Julia 1.6より前のバージョンでは、TerminalMenus.config()を呼び出してメニューを設定する方法も使えます。この方法はJulia 1.xの全バージョンで引き続きサポートされています。

Configuration

REPL.TerminalMenus.Config — Type
Config(; scroll_wrap=false, ctrl_c_interrupt=true, charset=:ascii, cursor::Char, up_arrow::Char, down_arrow::Char)

キーワード引数を使って、選択メニューの動作を設定します。

  • scroll_wrap が true の場合、最初の項目より上、または最後の項目より下へスクロールすると、メニューが先頭または末尾に戻ります。
  • ctrl_c_interrupt が true の場合、メニューの選択中に Ctrl-C を押すと InterruptException がスローされます。false の場合、TerminalMenus.request は TerminalMenus.selected のデフォルトの結果を返します。
  • charset は cursor、up_arrow、down_arrow のデフォルト値に影響し、:ascii または :unicode を指定できます。
  • cursor は、「Enter」キーを押すと選択される項目を示すために表示される文字です。デフォルトは、charset に応じて '>' または '→' です。
  • up_arrow は、最初の項目が表示範囲に含まれない場合に表示される文字です。デフォルトは、charset に応じて '^' または '↑' です。
  • down_arrow は、最後の項目が表示範囲に含まれない場合に表示される文字です。デフォルトは、charset に応じて 'v' または '↓' です。

ConfiguredMenu のサブタイプでは、必要に応じて cursor、up_arrow、down_arrow が自動的に表示されます。writeline メソッドでこれらを表示する必要はありません。

MultiSelectConfig(; charset=:ascii, checked::String, unchecked::String, kwargs...)

キーワード引数を使って、複数選択メニューの動作を設定します。

  • オプションが選択されているときに表示する文字列は checked です。デフォルトは、charset に応じて「[X]」または「✓」です。
  • オプションが選択されていないときに表示する文字列は unchecked です。デフォルトは、charset に応じて「[ ]」または「⬚」です。

その他のキーワード引数については、TerminalMenus.Config の説明を参照してください。checked と unchecked は自動では表示されないため、writeline メソッドで表示してください。

Julia 1.6

MultiSelectConfig は Julia 1.6 以降で利用できます。それ以前のバージョンでは、グローバルな CONFIG を使用してください。

REPL.TerminalMenus.config — Function
config( <see arguments> )

グローバルメニューのパラメーターを設定するキーワード専用関数

Arguments

  • charset::Symbol=:na: 使用するUI文字（:asciiまたは:unicode）。ほかの引数が指定された場合は上書きされます
  • cursor::Char='>'|'→': カーソルに使用する文字
  • up_arrow::Char='^'|'↑': 上矢印に使用する文字
  • down_arrow::Char='v'|'↓': 下矢印に使用する文字
  • checked::String="[X]"|"✓": チェック済みに使用する文字列
  • unchecked::String="[ ]"|"⬚"): 未チェックに使用する文字列
  • scroll::Symbol=:nowrap: :wrapの場合、カーソルは上下端で折り返します。:nowrapの場合、カーソルは折り返しません
  • supress_output::Bool=false: 互換性のために残されている引数ですが、無視されます。代わりにrequestにキーワード引数としてsuppress_outputを渡してください。
  • ctrl_c_interrupt::Bool=true: falseの場合、^Cで空を返します。trueの場合、^CでInterruptException()をスローします
Julia 1.6

Julia 1.6以降、configは非推奨です。代わりにConfigまたはMultiSelectConfigを使用してください。

REPL.TerminalMenus.request — Function
request(m::AbstractMenu; cursor=1)

メニューを表示して、対話モードに入ります。cursorは、初期カーソル位置に使用する項目番号を示します。cursorには、IntまたはRefValue{Int}を指定できます。後者を使うと、外部からカーソル位置を監視および制御できます。

selected(m)を返します。

REPL.TerminalMenus.writeline — Function
writeline(buf::IO, m::AbstractMenu, idx::Int, iscursor::Bool)

インデックス idx のオプションを buf に書き込みます。iscursor が true の場合、この項目が現在のカーソル位置（「Enter」キーを押すと選択される項目）にあることを示します。

m が ConfiguredMenu の場合、TerminalMenus がカーソルインジケーターを出力します。それ以外の場合は、呼び出し先が出力を処理することを想定しています。

Julia 1.6

writeline には Julia 1.6 以降が必要です。

それ以前の Julia バージョンでは、これは writeLine(buf::IO, m::AbstractMenu, idx, iscursor::Bool) であり、m は未設定とみなされます。選択インジケーターとカーソルインジケーターは TerminalMenus.CONFIG から取得できます。

この旧関数は Julia 1.x のすべてのバージョンでサポートされていますが、Julia 2.0 で削除される予定です。
