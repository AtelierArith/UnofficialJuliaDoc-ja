Artifacts

Starting with Julia 1.6, the artifacts support has moved from Pkg.jl to Julia itself. Until proper documentation can be added here, you can learn more about artifacts in the Pkg.jl manual at https://julialang.github.io/Pkg.jl/v1/artifacts/.

Julia 1.6

Julia's artifacts API requires at least Julia 1.6. In Julia versions 1.3 to 1.5, you can use Pkg.Artifacts instead.

Artifacts.artifact_meta — Function
artifact_meta(name::String, artifacts_toml::String;
              platform::AbstractPlatform = HostPlatform(),
              pkg_uuid::Union{Base.UUID,Nothing}=nothing)

指定した(Julia)Artifacts.tomlファイルに格納されている、名前で識別されるアーティファクトのメタデータを取得します。アーティファクトがプラットフォーム固有の場合は、最適なマッピングを選択するためにplatformを使用します。見つからない場合は、nothingを返します。

Julia 1.3

この関数を使用するには、Julia 1.3以降が必要です。

source
Artifacts.artifact_hash — Function
artifact_hash(name::String, artifacts_toml::String;
              platform::AbstractPlatform = HostPlatform())

指定されたプラットフォームに折りたたまれたアーティファクトのハッシュを返す、artifact_meta()の薄いラッパーです。対応するマッピングが見つからない場合は、nothingを返します。

Julia 1.3

この関数を使用するには、Julia 1.3 以降が必要です。

source
Artifacts.find_artifacts_toml — Function
find_artifacts_toml(path::String)

.jl ファイルのパス（マクロのコンテキストで __source__.file が返すパスなど）が与えられた場合、そのファイルを含むプロジェクト内にある (Julia)Artifacts.toml を探します。存在しない場合は nothing を返します。

Julia 1.3

この関数を使用するには、Julia 1.3 以降が必要です。

source
Artifacts.@artifact_str — Macro
macro artifact_str(name)

アーティファクトのディスク上のパスを返します。プロジェクトの(Julia)Artifacts.tomlファイルから、名前を指定してアーティファクトを自動的に検索します。指定したアーティファクトが見つからない場合はエラーをスローします。REPLで実行した場合は、カレントディレクトリからtomlファイルを検索します。詳しくはfind_artifacts_toml()を参照してください。

アーティファクトが「lazy」としてマークされており、パッケージでusing LazyArtifactsが定義されている場合、このマクロが初めてパスを計算しようとしたときに、Pkgを使ってアーティファクトがオンデマンドでダウンロードされます。ダウンロードされたファイルはローカルにインストールされ、その後も利用できます。

nameにスラッシュ（/または\）が含まれている場合、最初のスラッシュより後の要素は、アーティファクト内のパスを指定するものとして扱われます。これにより、アーティファクト内の単一のファイルやディレクトリに簡単なワンライナーでアクセスできます。例：

ffmpeg_path = @artifact"FFMPEG/bin/ffmpeg"
Julia 1.3

このマクロを使用するには、Julia 1.3以降が必要です。

Julia 1.6

スラッシュによるインデックス指定には、Julia 1.6以降が必要です。

source
Artifacts.artifact_exists — Function
artifact_exists(hash::SHA1; honor_overrides::Bool=true)

指定されたアーティファクト（sha1 の Git ツリーハッシュで識別）がディスク上に存在するかどうかを返します。指定されたアーティファクトが複数の場所（複数のデポ内など）に存在する場合もあります。

Julia 1.3

この関数を使用するには、Julia 1.3 以降が必要です。

source
Artifacts.artifact_path — Function
artifact_path(hash::SHA1; honor_overrides::Bool=true)

SHA1 Gitツリーハッシュで識別されるアーティファクトを指定すると、そのインストール先のパスを返します。アーティファクトが存在しない場合は、インストールされる予定の場所を返します。

Julia 1.3

この関数を使用するには、Julia 1.3以降が必要です。

source
Artifacts.select_downloadable_artifacts — Function
select_downloadable_artifacts(artifacts_toml::String;
                              platform = HostPlatform,
                              include_lazy = false,
                              pkg_uuid = nothing)

指定されたプラットフォーム向けにダウンロードする必要があるアーティファクトをすべて含む辞書を返します。各エントリは、指定されたArtifacts.tomlのアーティファクトです。include_lazyが設定されている場合は、遅延アーティファクトも含まれます。
