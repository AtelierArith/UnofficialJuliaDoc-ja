SHA

SHA functions

使い方はとても簡単です。

julia> using SHA

julia> bytes2hex(sha256("test"))
"9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08"

各エクスポート関数（執筆時点では、SHA-1、SHA-2の224、256、384、512、およびSHA-3の224、256、384、512の各関数が実装されています）は、AbstractVector{UInt8}、AbstractString、またはIOオブジェクトを受け取ります。これにより、ファイルのチェックサムを簡単に計算できます。

shell> cat /tmp/test.txt
test
julia> using SHA

julia> open("/tmp/test.txt") do f
           sha2_256(f)
       end
32-element Vector{UInt8}:
 0x9f
 0x86
 0xd0
 0x81
 0x88
 0x4c
 0x7d
 0x65
    ⋮
 0x5d
 0x6c
 0x15
 0xb0
 0xf0
 0x0a
 0x08

All SHA functions

sha256がsha2_256を指す口語的な用法があるため、shaxxx()の関数呼び出しをsha2_xxx()に対応付ける便利な関数が用意されています。SHA-3にはこのような通称がないため、完全なsha3_xxx()名を使用する必要があります。

shaxxx()は、AbstractStringおよび、要素の型がUInt8である配列風オブジェクト（NTupleおよびVector）を受け取ります。

Working with context

複数の項目からハッシュを作成するには、SHAX_XXX_CTX()型を使って状態を保持するハッシュオブジェクトを作成し、update!で更新してから、digest!で確定できます。

julia> using SHA

julia> ctx = SHA2_256_CTX()
SHA2 256-bit hash state

julia> update!(ctx, b"some data")
0x0000000000000009

julia> update!(ctx, b"some more data")
0x0000000000000017

julia> digest!(ctx)
32-element Vector{UInt8}:
 0xbe
 0xcf
 0x23
 0xda
 0xaf
 0x02
 0xf7
 0xa3
 0x57
 0x92
    ⋮
 0x89
 0x4f
 0x59
 0xd8
 0xb3
 0xb4
 0x81
 0x8b
 0xc5

なお、執筆時点ではSHA3のコードは最適化されていないため、SHA2よりおよそ1桁遅くなります。

SHA.update! — Function
update!(context, data[, datalen])

data 内のバイト列で SHA コンテキストを更新します。ハッシュの確定については、digest! も参照してください。

Examples

julia> ctx = SHA1_CTX()
SHA1 hash state

julia> update!(ctx, b"data to to be hashed")
source
SHA.digest! — Function
digest!(context)

SHAコンテキストを確定し、ハッシュをバイト配列（Vector{Uint8}）として返します。コンテキストに対してdigest!を呼び出した後に更新しようとすると、エラーになります。

Examples

julia> ctx = SHA1_CTX()
SHA1 hash state

julia> update!(ctx, b"data to to be hashed")

julia> digest!(ctx)
20-element Vector{UInt8}:
 0x83
 0xe4
 ⋮
 0x89
 0xf5

julia> update!(ctx, b"more data")
ERROR: Cannot update CTX after `digest!` has been called on it
[...]
source

HMAC functions

julia> using SHA

julia> key = collect(codeunits("key_string"))
10-element Vector{UInt8}:
 0x6b
 0x65
 0x79
 0x5f
 0x73
 0x74
 0x72
 0x69
 0x6e
 0x67

julia> bytes2hex(hmac_sha3_256(key, "test-message"))
"bc49a6f2aa29b27ee5ed1e944edd7f3d153e8a01535d98b5e24dac9a589a6248"

複数の項目からハッシュを作成するには、HMAC_CTX()型を使って状態を保持するハッシュオブジェクトを作成し、update!で更新してから、digest!で確定できます。

julia> using SHA

julia> key = collect(codeunits("key_string"))
10-element Vector{UInt8}:
 0x6b
 0x65
 0x79
 0x5f
 0x73
 0x74
 0x72
 0x69
 0x6e
 0x67

julia> ctx = HMAC_CTX(SHA3_256_CTX(), key);

julia> update!(ctx, b"test-")
0x0000000000000000000000000000008d

julia> update!(ctx, b"message")
0x00000000000000000000000000000094

julia> bytes2hex(digest!(ctx))
"bc49a6f2aa29b27ee5ed1e944edd7f3d153e8a01535d98b5e24dac9a589a6248"
