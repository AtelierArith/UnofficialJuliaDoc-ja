Calling Conventions

Juliaでは、3種類の呼び出し規約が4つの異なる目的で使われます。

名前プレフィックス目的
Nativejulia_特化したシグネチャによる高速化
JL Calljlcall_汎用呼び出し用のラッパー
JL Calljl_組み込み関数
C ABIjlcapi_Cから呼び出せるラッパー

Julia Native Calling Convention

ネイティブ呼び出し規約は、ジェネリックではない呼び出しを高速に行うために設計されています。通常、特化したシグネチャを使用します。

  • LLVMのゴースト（長さゼロの型）は省略されます。
  • LLVMのスカラーとベクトルは値渡しされます。
  • LLVMの集成体（配列と構造体）は参照渡しされます。

小さな戻り値はLLVMの戻り値として返されます。大きな戻り値は「構造体戻り値」（sret）規約を使って返されます。この場合、呼び出し側が戻り値用の領域へのポインターを渡します。

引数または戻り値が同種のタプルである場合、LLVM配列ではなくLLVMベクトルとして表現されることがあります。

JL Call Convention

JL Call規約は、組み込み関数とジェネリックディスパッチに使用されます。この規約を使う手書きの関数は、マクロJL_CALLABLEで宣言します。この規約では、パラメーターは正確に3つです。

  • F - 適用される関数のJulia表現
  • args - ボックスへのポインターを格納した配列へのポインター
  • nargs - 配列の長さ

戻り値はボックスへのポインターです。

C ABI

C ABIラッパーを使うと、CからJuliaを呼び出せます。このラッパーは、ネイティブ呼び出し規約を使って関数を呼び出します。

タプルは常にC配列として表現されます。
