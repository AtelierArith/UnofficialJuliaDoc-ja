Core.Builtins

以下の組み込み関数は不安定と見なされていますが、Juliaプログラムの能力や動作を定義する基本的な定義を提供します。通常は、より高水準の汎用APIを通じて利用します。

Raw access to memory

Core.Intrinsics.pointerref — Function
Core.Intrinsics.pointerref(p::Ptr{T}, i::Int, align::Int)

pから数えてi番目（1始まり）の要素のアドレスから、型Tの値を読み込みます。これはCの式p[i-1]と同等です。

アラインメントは2のべき乗である必要があります。0を指定すると、Tのデフォルトのアラインメントが使われます。p[i-1]が範囲外、無効、またはアラインメントされていない場合、動作は未定義です。アラインメントに1を指定すれば、常に安全です。

unsafe_loadも参照してください。

source
Core.Intrinsics.pointerset — Function
Core.Intrinsics.pointerset(p::Ptr{T}, x::T, i::Int, align::Int)

pから数えてi番目（1始まり）の要素のアドレスに、型Tの値を格納します。これはCの式p[i-1] = xと同等です。

アラインメントは2のべき乗である必要があります。0を指定すると、Tのデフォルトのアラインメントが使われます。p[i-1]が範囲外、無効、またはアラインメントされていない場合、動作は未定義です。アラインメントが1であれば、常に安全です。

関連項目：unsafe_store!。

Base.quoted — Function
quoted(x)

IR に定数として挿入しても安全な x を返します。ただし、AST への挿入が安全になるわけではありません。eval は AST オブジェクトの一部の型を内部にコピーすることがあり、また、コンテキストによっては内部の $ を評価して補間することもあります。

source

isa_ast_node(x)
