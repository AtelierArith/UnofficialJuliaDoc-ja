Base.AbstractIrrational — Type
AbstractIrrational <: Real

厳密な無理数値を表す数値型です。他の数値との算術演算では、結果が適切な精度に自動的に丸められます。

サブタイプ MyIrrational <: AbstractIrrational は、少なくとも ==(::MyIrrational, ::MyIrrational)、hash(x::MyIrrational, h::UInt)、convert(::Type{F}, x::MyIrrational) where {F <: Union{BigFloat,Float32,Float64}} を実装する必要があります。

サブタイプが有理数になる場合もある値を表すために使われる場合（たとえば、整数 n に対する √n を表す平方根型では、n が完全平方数なら有理数の結果になります）、さらに isinteger、iszero、isone、== も Real の値で実装する必要があります（これらはすべて、AbstractIrrational 型ではデフォルトで false になるため）。また、hash が対応する Rational と同じ値になるよう定義する必要があります。

Concrete number types

Core.Float16 — Type
Float16 <: AbstractFloat <: Real

16ビット浮動小数点数型（IEEE 754規格）。バイナリ形式は、符号部が1ビット、指数部が5ビット、仮数部が10ビットです。

source
Core.Float32 — Type
Float32 <: AbstractFloat <: Real

32ビット浮動小数点数型（IEEE 754規格）。2進形式は、符号部1ビット、指数部8ビット、仮数部23ビットです。

科学表記法の指数には、小文字のfを使用します。たとえば、2f3 === 2.0f0 * 10^3 === Float32(2_000)です。配列リテラルや内包表記では、角括弧の前に要素型を指定できます。Float32[1,4,9] == Float32[i^2 for i in 1:3]

関連項目：Inf32、NaN32、Float16、exponent、frexp。

source
Core.Float64 — Type
Float64 <: AbstractFloat <: Real

64ビット浮動小数点数型（IEEE 754規格）。2進形式は、符号部1ビット、指数部11ビット、仮数部52ビットです。各種ビットへのアクセス方法については、bitstring、signbit、exponent、frexp、significandを参照してください。

浮動小数点リテラルや1.0 isa Float64、1/2, 2pi, log(2), range(0,90,length=4)など多くの演算では、これがデフォルトです。整数とは異なり、このデフォルトはSys.WORD_SIZEによって変わりません。

科学表記法の指数は、eまたはEとして入力できます。つまり、2e3 === 2.0E3 === 2.0 * 10^3です。整数はオーバーフローするため、10^nよりもこの方法を強く推奨します。そのため、2.0 * 10^19 < 0ですが、2e19 > 0です。

関連項目：Inf、NaN、floatmax、Float32、Complex。

source

Core.Bool — Type
Bool <: Integer

値 true と false を持つブール型。

Bool は数値型の一種です。false は数値的に 0 と等しく、true は数値的に 1 と等しくなります。さらに、false は NaN および Inf に対して、乗法における「強いゼロ」として働きます。

julia> [true, false] == [1, 0]
true

julia> 42.0 + true
43.0

julia> 0 .* (NaN, Inf, -Inf)
(NaN, NaN, NaN)

julia> false .* (NaN, Inf, -Inf)
(0.0, 0.0, -0.0)

if などの条件分岐が受け付けるのは、Bool のみです。Julia に「truthy」な値はありません。

比較演算は通常 Bool を返しますが、ブロードキャストされた比較では Array{Bool} の代わりに BitArray が返されることがあります。

julia> [1 2 3 4 5] .< pi
1×5 BitMatrix:
 1  1  1  0  0

julia> map(>(pi), [1 2 3 4 5])
1×5 Matrix{Bool}:
 0  0  0  1  1

関連項目: trues、falses、ifelse。

source

Core.Int — Type
Int

Sys.WORD_SIZE ビットの符号付き整数型、Int <: Signed <: Integer <: Real。

ほとんどの整数リテラルで使われるデフォルトの型であり、Sys.WORD_SIZE に応じて Int32 または Int64 の別名になります。length などの関数が返す型であり、配列のインデックスに使われる標準的な型でもあります。

整数は警告なしにオーバーフローするため、typemax(Int) + 1 < 0 と 10^19 < 0 であることに注意してください。BigInt を使えば、オーバーフローを回避できます。非常に大きな整数リテラルには、たとえば 10_000_000_000_000_000_000 isa Int128 のように、より幅の広い型が使われます。

整数の除算は div、すなわち ÷ ですが、整数に対して / を使うと Float64 が返されます。

Int64、widen、typemax、bitstring も参照してください。

source
Core.UInt — Type
UInt

Sys.WORD_SIZE ビットの符号なし整数型、UInt <: Unsigned <: Integer。

Int と同様に、エイリアス UInt は、コンピューターごとの Sys.WORD_SIZE の値に応じて、UInt32 または UInt64 のいずれかを指します。

16 進数で出力・解析されます: UInt(15) === 0x000000000000000f。

Data Formats

Base.digits — Function
digits([T<:Integer], n::Integer; base::T = 10, pad::Integer = 1)

指定した基数での n の各桁を格納した、要素型が T（デフォルトは Int）の配列を返します。必要に応じて、指定したサイズになるようゼロでパディングできます。上位の桁ほどインデックスが大きくなり、n == sum(digits[k]*base^(k-1) for k in 1:length(digits)) となります。

ndigits、digits!、および基数 2 の場合は bitstring と count_ones も参照してください。

Examples

julia> digits(10)
2-element Vector{Int64}:
 0
 1

julia> digits(10, base = 2)
4-element Vector{Int64}:
 0
 1
 0
 1

julia> digits(-256, base = 10, pad = 5)
5-element Vector{Int64}:
 -6
 -5
 -2
  0
  0

julia> n = rand(-999:999);

julia> n == evalpoly(13, digits(n, base = 13))
true
source
Base.digits! — Function
digits!(array, n::Integer; base::Integer = 10)

指定された基数で、n の各桁を配列に格納します。上位の桁ほど大きなインデックスに格納されます。配列の長さが足りない場合は、下位の桁から配列の長さ分だけ格納します。配列が長すぎる場合は、余った部分をゼロで埋めます。

Examples

julia> digits!([2, 2, 2, 2], 10, base = 2)
4-element Vector{Int64}:
 0
 1
 0
 1

julia> digits!([2, 2, 2, 2, 2, 2], 10, base = 2)
6-element Vector{Int64}:
 0
 1
 0
 1
 0
 0

Base.parse — Function
parse(::Type{SimpleColor}, rgb::String)

tryparse(SimpleColor, rgb::String)（そちらを参照）の類似関数で、nothingを返す代わりにエラーを発生させます。

source
parse(type, str; base)

文字列を数値として解析します。Integer 型では基数を指定できます（既定値は 10 です）。浮動小数点型の場合、文字列は 10 進浮動小数点数として解析されます。Complex 型は、"R±Iim" 形式の 10 進文字列から、要求された型の Complex(R,I) として解析されます。"im" の代わりに "i" または "j" を使用することもでき、"R" または "Iim" も使用できます。文字列に有効な数値が含まれていない場合は、エラーが発生します。

Julia 1.1

parse(Bool, str) を使用するには、Julia 1.1 以降が必要です。

Examples

julia> parse(Int, "1234")
1234

julia> parse(Int, "1234", base = 5)
194

julia> parse(Int, "afc", base = 16)
2812

julia> parse(Float64, "1.2e-3")
0.0012

julia> parse(Complex{Float64}, "3.2e-1 + 4.5im")
0.32 + 4.5im
source
parse(::Type{Platform}, triplet::AbstractString)

文字列のプラットフォームトリプレットを解析し、Platform オブジェクトに戻します。

source
Base.tryparse — Function
tryparse(::Type{SimpleColor}, rgb::String)

rgbをSimpleColorとして解析します。rgbが#で始まり、長さが7の場合、RGBTupleを基盤とするSimpleColorに変換されます。rgbがa-zで始まる場合、rgbは色名として解釈され、Symbolを基盤とするSimpleColorに変換されます。

それ以外の場合は、nothingが返されます。

Examples

julia> tryparse(SimpleColor, "blue")

julia> tryparse(SimpleColor, "#9558b2")

julia> tryparse(SimpleColor, "#nocolor")
source
tryparse(type, str; base)

Base.Math.significand — Function

Base.Math.exponent — Function
exponent(x::Real)::Int

y を返す最大の整数 2^y ≤ abs(x)。正規化された浮動小数点数 x の場合、これは x の指数に相当します。

x がゼロ、無限大、または NaN の場合、DomainError をスローします。その他の非サブノーマル浮動小数点数 x では、これは x の指数ビットに相当します。

Julia 1.14

exponent を Bool に対して呼び出すには、Julia 1.14 以降が必要です。

関連項目: signbit、significand、frexp、issubnormal、log2、ldexp。

Examples

julia> exponent(8)
3

julia> exponent(6.5)
2

julia> exponent(-1//4)
-2

julia> exponent(3.142e-4)
-12

julia> exponent(floatmin(Float32)), exponent(nextfloat(0.0f0))
(-126, -149)

julia> exponent(0.0)
ERROR: DomainError with 0.0:
Cannot be ±0.0.
[...]

Base.hex2bytes — Function
hex2bytes(itr)

16進数の各桁を表すASCIIコードの反復可能オブジェクト itr を受け取り、その2進表現に対応するバイト列 Vector{UInt8} を返します。itr の連続する各2桁の16進数が、返されるベクトル内の1バイトの値になります。

itr の長さは偶数でなければなりません。返される配列の長さは itr の半分です。インプレース版については hex2bytes! を、逆変換については bytes2hex を参照してください。

Julia 1.7

hex2bytes を呼び出す際、UInt8 の値を生成するイテレーターを使うには、Julia 1.7 以降が必要です。それ以前のバージョンでは、hex2bytes を呼び出す前にイテレーターを collect できます。

Examples

julia> s = string(12345, base = 16)
"3039"

julia> hex2bytes(s)
2-element Vector{UInt8}:
 0x30
 0x39

julia> a = b"01abEF"
6-element Base.CodeUnits{UInt8, String}:
 0x30
 0x31

BigFloats and BigInts

The BigFloat and BigInt types implement arbitrary-precision floating point and integer arithmetic, respectively. For BigFloat the GNU MPFR library is used, and for BigInt the [GNU Multiple Precision Arithmetic Library (GMP)] (https://gmplib.org) is used.

Base.MPFR.BigFloat — Method
BigFloat(x::Union{Real, AbstractString} [, rounding::RoundingMode=rounding(BigFloat)]; [precision::Integer=precision(BigFloat)])

xから、精度precisionの任意精度浮動小数点数を作成します。変換を正確に行えない場合に、結果をどの方向に丸めるかはrounding引数で指定します。省略した場合は、現在のグローバル値が使われます。

BigFloat(x::Real)はconvert(BigFloat,x)と同じですが、x自体がすでにBigFloatの場合は例外です。この場合、精度が現在のグローバル精度に設定された値を返します。一方、convertは常にxを返します。

BigFloat(x::AbstractString)はparseと同じです。10進リテラルはパース時にFloat64へ変換されるため、BigFloat(2.1)が期待どおりの結果にならないことがあります。このため、便宜上用意されています。

関連項目:

  • @big_str
  • roundingおよびsetrounding
  • precisionおよびsetprecision
Julia 1.1

キーワード引数としてprecisionを使うには、Julia 1.1以降が必要です。Julia 1.0では、precisionは2番目の位置引数です（BigFloat(x, precision)）。

Examples

julia> BigFloat(2.1) # 2.1 here is a Float64
2.100000000000000088817841970012523233890533447265625

julia> BigFloat("2.1") # the closest BigFloat to 2.1
2.099999999999999999999999999999999999999999999999999999999999999999999999999986

julia> BigFloat("2.1", RoundUp)

julia> BigFloat("2.1", RoundUp, precision=128)
