Iteration utilities

Base.Iterators.Stateful — Type
Stateful(itr)

このイテレーターラッパーは、いくつかの異なる観点から捉えることができます。

  1. イテレーターとその反復状態を包む、変更可能なラッパーです。
  2. イテレーターのような抽象化を、Channelのような抽象化に変換します。
  3. 要素を生成するたびに、自身の残りのイテレーターへと変化するイテレーターです。

Statefulは、標準的なイテレーターインターフェースを提供します。他の変更可能なイテレーター（例：Base.Channel）と同様に、反復を途中で停止した場合（例：forループ内でbreakを使った場合）、同じイテレーターオブジェクトに対する反復を続ければ、停止した位置から再開できます（これに対し、変更不可能なイテレーターでは先頭から再開します）。

Examples

julia> a = Iterators.Stateful("abcdef");

julia> isempty(a)
false

julia> popfirst!(a)
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> collect(Iterators.take(a, 3))
3-element Vector{Char}:
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)

julia> collect(a)
2-element Vector{Char}:
 'e': ASCII/Unicode U+0065 (category Ll: Letter, lowercase)
 'f': ASCII/Unicode U+0066 (category Ll: Letter, lowercase)

julia> Iterators.reset!(a); popfirst!(a)
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> Iterators.reset!(a, "hello"); popfirst!(a)
'h': ASCII/Unicode U+0068 (category Ll: Letter, lowercase)
julia> a = Iterators.Stateful([1,1,1,2,3,4]);

julia> for x in a; x == 1 || break; end

julia> peek(a)
3

julia> sum(a) # Sum the remaining elements
7

Base.Iterators.zip — Function
zip(iters...)

複数のイテレータを同時に実行し、いずれかが使い果たされるまで値を生成します。zip の値の型は、サブイテレータの値を要素とするタプルです。

Note

zip は、あるイテレータが現在の反復で終了した場合に、状態を持つほかのイテレータが進まないよう、サブイテレータの呼び出し順序を調整します。

Note

引数なしで zip() を呼び出すと、空のタプルを無限に生成するイテレータが返されます。

関連項目: enumerate、Base.splat。

Examples

julia> a = 1:5
1:5

julia> b = ["e","d","b","c","a"]
5-element Vector{String}:
 "e"
 "d"
 "b"
 "c"
 "a"

julia> c = zip(a,b)
zip(1:5, ["e", "d", "b", "c", "a"])

julia> length(c)
5

julia> first(c)
(1, "e")

Base.Iterators.enumerate — Function
enumerate(iter)

(i, x)を返すイテレータです。iは1から始まるカウンターで、xは、与えられたイテレータのi番目の値です。反復対象の値xだけでなく、これまでの反復回数も必要な場合に便利です。

iは、iterのインデックスとして有効とは限らず、別の要素を指す場合もあります。これは、iterのインデックスが1から始まらない場合に起こります。また、文字列や辞書などでも起こることがあります。iがインデックスであることを確実にしたい場合は、pairs(IndexLinear(), iter)メソッドを参照してください。

Examples

julia> a = ["a", "b", "c"];

julia> for (index, value) in enumerate(a)
           println("$index $value")
       end
1 a
2 b
3 c

julia> str = "naïve";

julia> for (i, val) in enumerate(str)
           print("i = ", i, ", val = ", val, ", ")
           try @show(str[i]) catch e println(e) end
       end
i = 1, val = n, str[i] = 'n'
i = 2, val = a, str[i] = 'a'
i = 3, val = ï, str[i] = 'ï'
i = 4, val = v, StringIndexError("naïve", 4)
i = 5, val = e, str[i] = 'v'
source

Base.Iterators.cycle — Function
cycle(iter[, n::Int])

iterを無限に繰り返すイテレータです。nを指定すると、iterをその回数だけ繰り返します。iterが空の場合、cycle(iter)とcycle(iter, n)も空になります。

Iterators.cycle(iter, n)はBase.repeat(vector, n)の遅延評価版です。また、Iterators.repeated(iter, n)は、Base.fill(item, n)の遅延評価版です。

Julia 1.11

メソッドcycle(iter, n)はJulia 1.11で追加されました。

Examples

julia> for (i, v) in enumerate(Iterators.cycle("hello"))
           print(v)
           i > 10 && break
       end
hellohelloh

julia> foreach(print, Iterators.cycle(['j', 'u', 'l', 'i', 'a'], 3))
juliajuliajulia

julia> repeat([1,2,3], 4) == collect(Iterators.cycle([1,2,3], 4))
true

julia> fill([1,2,3], 4) == collect(Iterators.repeated([1,2,3], 4))
true
source

Base.Iterators.filter — Function
Iterators.filter(flt, itr)

述語関数 flt と反復可能オブジェクト itr を受け取り、反復すると itr の要素のうち flt(x) を満たすもの x を返す反復可能オブジェクトを返します。元のイテレーターの順序は保持されます。

この関数は 遅延評価 されます。つまり、$Θ(1)$ 時間で返り、追加で使用する領域は $Θ(1)$ であることが保証されます。また、filter の呼び出しによって flt が呼び出されることはありません。flt は、返された反復可能オブジェクトを反復するときに呼び出されます。これらの呼び出しはキャッシュされないため、再度反復すると再び呼び出されます。

Warning

filter が返すイテレーターに対して、Iterators.reverse や cycle による処理など、後続の 遅延評価 変換を行った場合も、返された反復可能オブジェクトを収集または反復するまで flt の呼び出しは遅延されます。フィルター述語が非決定的である場合や、その戻り値が itr の要素を反復する順序に依存する場合、遅延変換と組み合わせると予期しない動作になることがあります。これを避けるには、flt が純粋関数であることを確認するか、後続の変換を行う前に中間の filter イテレーターを収集してください。

配列に対するフィルタリングの即時評価版については、Base.filter を参照してください。

Examples

julia> f = Iterators.filter(isodd, [1, 2, 3, 4, 5])
Base.Iterators.Filter{typeof(isodd), Vector{Int64}}(isodd, [1, 2, 3, 4, 5])

julia> foreach(println, f)
1
3
5

julia> [x for x in [1, 2, 3, 4, 5] if isodd(x)]  # collects a generator over Iterators.filter
3-element Vector{Int64}:
 1
 3
 5
source

Base.Iterators.reverse — Function
Iterators.reverse(itr)

イテレータ itr が与えられたとき、reverse(itr) は同じコレクションを逆順にたどるイテレータです。このイテレータは、逆順にするためにコレクションのコピーを作成しない「遅延」型です。コピーを作成する実装については、Base.reverse を参照してください。

（デフォルトでは、itr をラップする Iterators.Reverse オブジェクトを返します。このオブジェクトは、対応する iterate メソッドが定義されていれば反復可能です。ただし、一部の itr 型では、より特化した Iterators.reverse の動作が実装されている場合があります。）

すべてのイテレータ型 T が逆順の反復をサポートしているわけではありません。T がサポートしていない場合、Iterators.reverse(itr::T) を反復しようとすると、Iterators.Reverse{T} 用の iterate メソッドがないため、MethodError がスローされます。（これらのメソッドを実装するには、r::Iterators.Reverse{T} オブジェクトから r.itr によって元のイテレータ itr::T を取得できます。より一般的には、Iterators.reverse(r) を使用できます。）

Examples

julia> foreach(println, Iterators.reverse(1:5))
5
4
3
2
1
source
