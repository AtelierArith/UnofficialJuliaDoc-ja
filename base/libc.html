Base.Libc.free — Function
free(addr::Ptr)

C標準ライブラリのfreeを呼び出してください。これは、mallocから取得したメモリに対してのみ使用し、ほかのCライブラリから取得したポインタには使用しないでください。Cライブラリから取得したPtrオブジェクトは、そのライブラリで定義されている解放関数を使って解放してください。システムに複数のlibcライブラリが存在する場合に、アサーション失敗が起きるのを防ぐためです。

source
Base.Libc.errno — Function
errno([code])

C ライブラリの errno の値を取得します。引数を指定すると、その値を errno に設定します。

errno の値が有効なのは、それを設定する C ライブラリルーチンを ccall した直後だけです。具体的には、REPL で次のプロンプトに errno を呼び出すことはできません。プロンプト間では多くのコードが実行されるためです。

Base.Libc.strptime — Function
strptime([format], timestr)

書式付きの時刻文字列を解析し、秒、分、時、日付などを表す TmStruct を返します。対応する書式は、標準 C ライブラリと同じです。一部のプラットフォームでは、タイムゾーンが正しく解析されないことがあります。この関数の結果を time に渡してエポックからの秒数に変換する場合は、isdst フィールドを手動で設定してください。このフィールドを -1 に設定すると、C ライブラリは現在のシステム設定を使ってタイムゾーンを判定します。

source

TmStruct([seconds])

エポックからの経過秒数を、sec、min、hour、mday、month、year、wday、yday、isdstの各フィールドを持つ分解形式に変換します。

Base.Libc.FILE — Type
FILE(::Ptr)
FILE(::IO)

開かれたファイルを表す libc FILE*。

ccall の引数として Ptr{FILE} を渡すことができ、seek、position、close もサポートします。

通常の IO オブジェクトが開かれたファイルであれば、そこから FILE を作成できます。作成後は必ず閉じてください。

Examples

julia> using Base.Libc

julia> mktemp() do _, io
           # write to the temporary file using `puts(char*, FILE*)` from libc
           file = FILE(io)
           ccall(:fputs, Cint, (Cstring, Ptr{FILE}), "hello world", file)
           close(file)
           # read the file again
           seek(io, 0)
           read(io, String)
       end
"hello world"
