```julia
randn([rng=default_rng()], [T=Float64], [dims...])
```

平均 0、標準偏差 1 の正規分布に従う `T` 型の乱数を生成します。省略可能な `dims` 引数を指定すると、サイズ `dims` の配列に、同じ分布に従う乱数を生成します。Julia の標準ライブラリでは、[`rand`](@ref) を実装する任意の浮動小数点型に対して `randn` をサポートしています。たとえば、`Base` 型の [`Float16`](@ref)、[`Float32`](@ref)（デフォルト）、[`Float64`](@ref)、[`BigFloat`](@ref)、およびそれらに対応する [`Complex`](@ref) が該当します。

（`T` が複素数の場合、分散 1 の円対称複素正規分布から値が生成されます。この分布では、実部と虚部は独立で、平均 0、分散 `1/2` の正規分布に従います。）

インプレースで処理するには [`randn!`](@ref) も参照してください。

# Examples

単一の乱数を生成する場合（デフォルトの `Float64` 型）：

```julia-repl
julia> randn()
-0.942481877315864
```

正規分布に従う乱数の行列を生成する場合（デフォルトの `Float64` 型）：

```julia-repl
julia> randn(2,3)
2×3 Matrix{Float64}:
  1.18786   -0.678616   1.49463
 -0.342792  -0.134299  -1.45005
```

再現可能な乱数を得るため、ユーザー定義のシードで乱数生成器 `rng` を初期化し、それを使って `Float32` 型の乱数、または `ComplexF32` 型の乱数行列を生成します。

```jldoctest
julia> using Random

julia> rng = Xoshiro(123);

julia> randn(rng, Float32)
-0.6457307f0

julia> randn(rng, ComplexF32, (2, 3))
2×3 Matrix{ComplexF32}:
  -1.03467-1.14806im  0.693657+0.056538im   0.291442+0.419454im
 -0.153912+0.34807im    1.0954-0.948661im  -0.543347-0.0538589im
```
