Julia v1.13 Release Notes

New language features

  • 最も内側で囲んでいる関数を参照する新しい@__FUNCTION__マクロ（#58940）。
  • Unicode 16で新たに追加された文字U+1F8B2 🢲（RIGHTWARDS ARROW WITH LOWER HOOK）が、矢印の優先順位を持つ有効な演算子になりました。REPLでは\hookunderrightarrowとして入力できます（[JuliaLang/JuliaSyntax.jl#525]、#57143）。
  • Unicode 17をサポート（#59534）。

Language changes

  • @docの戻り値が変更されました。以前のバージョンのようにDocs.Bindingオブジェクトを返すのではなく、ドキュメントに記載された式（関数や型など）を返すようになりました。@docがDocs.Bindingを返すことに依存していたコードは、更新が必要です（#59882、#60681）。
  • hashのアルゴリズムと戻り値が、一部の型、特にAbstractStringで変更されました。変更対象と同じ型に対するhashの特殊化（サードパーティ製文字列パッケージの一部など）は、削除が必要になる場合があります（#57509、#59691）。
  • hash(::AbstractString)関数は、codeunit関数とiterate関数を正しく実装することで、コピーもコストも発生しない関数になりました。サードパーティ製文字列パッケージでは、既存のhash関数のオーバーライドを削除し、新しいアルゴリズムに移行してください（#59691）。

Command-line option changes

  • オプション--sysimage-native-code=noは非推奨になりました。
  • 環境変数JULIA_CPU_TARGETで、現在のシステムイメージのビルドに使用されたCPUターゲットに一致する（またはそれを拡張する）ためのキーワードsysimageが使えるようになりました（#58970）。
  • --code-coverage=allオプションは、システムイメージ内のメソッドのコードカバレッジを正確に測定できるよう、システムイメージのキャッシュを自動的に破棄するようになりました。キャッシュは起動後（startup.jlの実行後）、ユーザーコードの実行前に破棄されます（#59234）。
  • トップレベル評価中に評価される式を表示する、新しいコマンドラインオプション--trace-evalが追加されました。--trace-eval=locまたは単に--trace-eval（位置のみ表示）、--trace-eval=full（式全体を表示）、--trace-eval=no（トレースを無効化）を指定できます。また、コマンドラインオプションより優先されるグローバル制御Base.TRACE_EVALも追加されました。これは:no、:loc、:full、またはnothing（コマンドライン設定を使用）に設定できます（#57137）。
  • CIデバッグが有効になった場合、Juliaは詳細なデバッグオプション（--trace-evalおよびJULIA_TEST_VERBOSE）を自動的に有効にするようになりました。たとえば、GitHub Actionsの再実行時に「debug logging」UIトグルを有効にした場合です。他のプラットフォームにも対応しています（#59551）。

Multi-threading changes

  • SpinLock <: AbstractSpinLockを使った新しいAbstractSpinLockが定義されました（#55944）。
  • 新しいPaddedSpinLock <: AbstractSpinLockが定義されました。誤共有を避けるため、追加のパディングが設けられています（#55944）。
  • Apple Siliconでは、Sys.CPU_THREADSとSys.EFFECTIVE_CPU_THREADSが、高性能コアの層だけでなく、すべてのCPUコアを数えるようになりました。これにより、次のデフォルト設定が影響を受けます。--threads=auto（JULIA_NUM_THREADS=auto）、--gcthreadsのデフォルト、--procs=auto、Distributed.addprocs()、JULIA_NUM_PRECOMPILE_TASKS。検出されたコア数を上書きするには、JULIA_CPU_THREADSを設定してください。パフォーマンスコアを判定するヒューリスティックは改善され、LinearAlgebraに移されました。引き続き、BLASスレッドプールのデフォルトサイズの決定に使われます（#62891、JuliaLang/LinearAlgebra.jl#1686）。

New library functions

  • Base.acquire(f, s::Base.Semaphore)の非クロージャ版であるBase.@acquireマクロが追加されました。@lockに似ています（#56845）。
  • 汎用イテラブルのn番目の要素にアクセスするnth関数が追加されました（#56580）。
  • パフォーマンスと利便性のため、ispositive(::Real)とisnegative(::Real)が提供されます（#53677）。
  • 構造体のフィールドのインデックスを取得するfieldindex関数がエクスポートされるようになりました（#58119）。
  • Base.donotdeleteが公開APIになりました。引数がデッドコード除去されるのを防ぎます（#55774）。
  • Sys.sysimage_target()は、現在のシステムイメージのビルドに使用されたCPUターゲット文字列を返します（#58970）。
  • Iterators.findeachは、findallの遅延評価版です（#54124）。

New library features

  • fieldoffsetは、fieldtypeと同様に、フィールド名をシンボルとしても受け取れるようになりました（#58100）。
  • sort(keys(::Dict))とsort(values(::Dict))は、自動的にコレクトするようになりました。以前は例外をスローしていました（#56978）。
  • 1始まりの軸のスーパータイプとしてBase.AbstractOneToが追加され、そのサブタイプとしてBase.OneToが定義されました（#56902）。
  • takestring!(::IOBuffer)はバッファーの内容を取り除き、その内容をStringとして返します。
  • chopprefixとchopsuffixは、削除する接頭辞／接尾辞としてAbstractCharも受け取れるようになりました。
  • macroexpand関数（デフォルトはtrue）と、新しいmacroexpand!関数（デフォルトはfalse）で、結果に対して従来のスコープ解決処理を実行するかどうかを制御する、ブール値のキーワード引数legacyscopeが使えるようになりました。従来のスコープ解決コードには既知の設計上の問題があり、将来のバージョンではデフォルトで無効になります。今のうちにlegacyscope=falseを呼び出すか、macroexpand!を使って移行してください。そのためには、macroexpandをMeta.unescapeおよびMeta.reescapeとともに呼び出すコードの修正や、結果にhygienic-scopeまたはescapeマーカーが現れることを想定したテストへの更新が必要になる場合があります。
  • コールバックOncePerProcess{T}を使ってデフォルト値を計算するスコープ付き値のために、Base.ScopedValues.LazyScopedValue{T}が導入されました。これにより、デフォルト値を遅延初期化できます。AbstractScopedValueは、ScopedValueとLazyScopedValueの両方に共通する抽象基底型になりました（#59372）。
  • アクティブなマニフェストのパスを返す新しい関数Base.active_manifest()が追加されました。Base.active_project()と同様に、指定したプロジェクトファイルで使用されるマニフェストも返せます（#57937）。

Standard library changes

  • mod(x::AbstractFloat, -Inf)は、xが有限であれば、xを返すようになりました。これはC標準に準拠する変更であり、バグ修正とみなされます（#47102）。
  • ReinterpretArrayに対する、インデックスを指定しないgetindexおよびsetindex!（つまりA[]）は、要素が複数ある場合に正しくBoundsErrorをスローするようになりました（#58814）。
  • randperm!とrandcycle!は、ArrayではないAbstractArray入力もサポートするようになりました。ただし、入力は変更可能で、インデックスが1始まりである必要があります（#58596）。
  • shuffleは、NTuple引数を受け取れるようになりました（#56906）。

REPL

  • Julia REPLがWindowsでブラケット付きペーストに対応しました。これにより、大きなコードブロックをREPLに貼り付ける速度が大幅に向上するはずです（#59825）。
  • REPLで、入力中の構文ハイライトが表示されるようになりました。カスタマイズについてはREPLのドキュメントを参照してください。
  • REPLで、閉じ括弧、閉じ丸括弧、閉じ引用符が自動挿入されるようになりました。カスタマイズについてはREPLのドキュメントを参照してください。
  • 履歴検索が書き直され、fzf風の新しい対話型モーダルダイアログを使うようになりました。
  • メインのREPLモードでAbstractCharを表示する際、ヘルプモードと同様にLaTeX入力情報も表示されるようになりました（#58181）。
  • スタックトレース内で、繰り返し現れるフレームや循環を括弧で囲み、一貫して扱うことで、表示が改善されました（#55841）。
  • 言語ではすでにサポートされていた上付き文字U+107A5 𐞥（MODIFIER LETTER SMALL Q）を、REPLで\^qとして入力できるようになりました（#59544）。

Test

  • Testが環境変数JULIA_TEST_VERBOSEに対応しました。trueに設定すると、テストセットの開始・終了時にタイミング情報付きの詳細メッセージを表示し、DefaultTestSetで詳細な階層型テストサマリーを表示するためのデフォルトverbose=trueを設定します（#59295）。
  • @testマクロを使ったテストの失敗時に、すべての関数呼び出しについて評価済みの引数が表示されるようになりました（#57825、#57839）。
  • 透過的なテストセット（@testset let）で、テストがエラーになった際にコンテキストが表示されるようになりました（#58727）。
  • @test_throwsで、例外の型とメッセージパターンの両方を1回の呼び出しで検証する3引数形式@test_throws ExceptionType pattern exprが使えるようになりました（#59117）。
  • テストセットのスタックが、タスクローカルストレージではなくScopedValueを使うように変更されました（#53462）。

InteractiveUtils

  • @code_typed、@which、@editなどのイントロスペクションユーティリティで、値の代わりに型注釈を指定できるようになりました。f(1, ::Float64, 3)やsum(::Vector{T}; init = ::T) where {T<:Real}のような形式も認識されます。型注釈から必要な情報が得られる場合、f(val::Int; kw::Float64)のような型注釈付き変数は評価されません。そのため、スタックトレースに現れるシグネチャと互換性があります（#57909、#58222）。
  • @code_loweredや@code_typedなどのコードイントロスペクションマクロで、ブロードキャスト式が大幅にサポート強化されました。x .+= f(y)の形式のブロードキャスト代入にも対応しています（#58349）。

Dates

  • 週単位のカレンダー向けに、isoweekdate、isoyear、weeksinyearが実装され、エクスポートされるようになりました。ISO week dateに準拠しています（#48507）。

External dependencies

  • 7-Zipがp7zip v17.06から上流版7-Zip v25.01に更新されました。Windowsでは、7z.exe/7z.dllの完全なバンドルがスタンドアロンの7za.exeに置き換えられました。対応形式は少なくなりますが、プラットフォーム間の動作が統一されます（#60025）。

Deprecated or removed

  • メソッドmerge(combine::Callable, d::AbstractDict...)は非推奨となり、代わりにmergewithを使うようになりました（#59775）。
