Mathematical Operations and Elementary Functions

Juliaは、すべての基本数値型に対して基本的な算術演算子とビット演算子を一通り備えています。また、標準的な数学関数も幅広くそろえ、移植性と効率に優れた実装を提供します。

Arithmetic Operators

次のarithmetic operatorsは、すべての基本数値型で使用できます。

式名前説明
+x単項プラス恒等演算
-x単項マイナス値を加法逆元に写す
x + y二項プラス加算を行う
x - y二項マイナス減算を行う
x * y乗算乗算を行う
x / y除算除算を行う
x ÷ y整数除算x / yを整数に切り捨てる
x \ y逆除算y / xと同等
x ^ yべき乗xをy乗する
x % y剰余rem(x, y)と同等

数値リテラルを識別子や括弧の直前に置くと（例：2x、2(x + y)）、他の二項演算より優先順位の高い乗算として扱われます。詳しくはNumeric Literal Coefficientsを参照してください。

Juliaの型昇格システムにより、異なる型の引数が混在する算術演算も自然かつ自動的に実行できます。型昇格システムの詳細はConversion and Promotionを参照してください。

÷記号は、REPLまたはJulia IDEで\div<tab>と入力すると簡単に入力できます。詳しくはmanual section on Unicode inputを参照してください。

算術演算子の簡単な使用例を示します。

julia> 1 + 2 + 3
6

julia> 1 - 2
-1

julia> 3*2/12
0.5

（慣例として、近くにある他の演算子より先に適用される演算子は、間隔を詰めて書くことが多いです。たとえば、まずxを否定し、その結果に2を加えることを表すため、通常は-x + 2と書きます。）

Boolean Operators

次のBoolean operatorsは、Bool型で使用できます。

式名前
!x否定
x && yshort-circuiting and
x || yshort-circuiting or

否定演算は、trueをfalseに、またその逆に変換します。短絡評価を行う演算については、リンク先のページで説明しています。

Arithmetic operations with Bool values

Boolは整数型であり、falseは数値として0と等しく、trueは数値として1と等しいことに注意してください。通常の型昇格規則と数値演算子もすべて定義されていますが、すべての引数がBoolの場合、算術演算（ブール演算以外）には特別な動作があります。この場合、引数の型はそのまま維持されず、Intに昇格されます。たとえば、Boolを使った演算と、別の数値型（UInt8）を使った演算が同じ結果になることを、次の例で確認できます。

julia> true - true
0

julia> 0x01 - 0x01
0x00

また、乗算に使う場合、falseは「強いゼロ」として働きます。

julia> NaN * false
0.0

julia> false * Inf
0.0

これは、ゼロであることが分かっている量にNaN値が伝播するのを防ぐのに役立ちます。この機能の背景についてはKnuth (1992)を参照してください。

Bitwise Operators

次のbitwise operatorsは、すべての基本整数型で使用できます。

式名前
~xビット否定
x & yビット積
x | yビット和
x ⊻ yビット排他的論理和（xor）
x ⊼ yビット否定論理積（nand）
x ⊽ yビット否定論理和（nor）
x >>> ylogical shift右シフト
x >> yarithmetic shift右シフト
x << y論理／算術左シフト

ビット演算子の使用例を示します。

julia> ~123
-124

julia> 123 & 234
106

julia> 123 | 234
251

julia> 123 ⊻ 234
145

julia> xor(123, 234)
145

julia> nand(123, 123)
-124

julia> 123 ⊼ 123
-124

julia> nor(123, 124)
-128

julia> 123 ⊽ 124
-128

julia> ~UInt32(123)
0xffffff84

julia> ~UInt8(123)
0x84

Updating operators

すべての二項算術演算子とビット演算子には、演算結果を左オペランドに代入する更新版もあります。二項演算子の直後に=を置くと、更新版になります。たとえば、x += 3と書くのは、x = x + 3と書くのと同じです。

julia> x = 1
1

julia> x += 3
4

julia> x
4

二項算術演算子とビット演算子の更新版は次のとおりです。

+=  -=  *=  /=  \=  ÷=  %=  ^=  &=  |=  ⊻=  >>>=  >>=  <<=
Note

更新演算子は左辺の変数を再束縛します。そのため、変数の型が変わることがあります。

julia> x = 0x01; typeof(x)
UInt8

julia> x *= 2 # Same as x = x * 2
2

julia> typeof(x)
Int64

Vectorized "dot" operators

^のような二項演算には、それぞれ対応する「ドット」演算.^があり、配列に対して^を要素ごとに実行するよう自動的に定義されています。たとえば、（正方でない）配列の「3乗」には標準的な数学上の意味がないため、[1, 2, 3] ^ 3は定義されていません。一方、[1, 2, 3] .^ 3は、要素ごと（または「ベクトル化」）の結果[1^3, 2^3, 3^3]を計算するものとして定義されています。!や√のような単項演算子にも、演算を要素ごとに適用する対応する.√があります。

julia> [1, 2, 3] .^ 3
3-element Vector{Int64}:
  1
  8
 27

より具体的には、a .^ bは"dot" call (^).(a,b)として構文解析され、broadcast演算を実行します。配列とスカラー、同じサイズの配列（要素ごとに演算）、さらには形状の異なる配列（たとえば、行ベクトルと列ベクトルを組み合わせて行列を生成する場合）も扱えます。また、ベクトル化された「ドット呼び出し」と同様に、これらの「ドット演算子」は融合されます。たとえば、配列Aに対して2 .* A.^2 .+ sin.(A)を計算すると（または@.マクロを使って@. 2A^2 + sin(A)と書くと）、Aを一度だけループし、Aの各要素aについて2a^2 + sin(a)を計算します。特に、f.(g.(x))のような入れ子のドット呼び出しは融合され、「隣接する」二項演算子x .+ 3 .* x.^2は、入れ子のドット呼び出し(+).(x, (*).(3, (^).(x, 2)))と同等です。

さらに、a .+= b（または@. a += b）のような「ドット付き」更新演算子は、a .= a .+ bとして構文解析されます。ここで.=は、融合されたインプレース代入演算です（dot syntax documentationを参照）。

ドット構文はユーザー定義演算子にも適用できます。たとえば、クロネッカー積（kron）を表す便利な中置記法A ⊗ Bとして⊗(A, B) = kron(A, B)を定義すると、追加のコードなしで[A, B] .⊗ [C, D]が[A⊗C, B⊗D]を計算します。

ドット演算子と数値リテラルを組み合わせると、解釈が曖昧になることがあります。たとえば、1.+xが1. + xを意味するのか、1 .+ xを意味するのかは明確ではありません。そのため、この構文は使用できません。このような場合は、演算子の前後に空白を入れる必要があります。

Numeric Comparisons

すべての基本数値型に、標準的な比較演算が定義されています。

演算子名前
==等しい
!=, ≠等しくない
<より小さい
<=, ≤以下
>より大きい
>=, ≥以上

簡単な例を示します。

julia> 1 == 1
true

julia> 1 == 2
false

julia> 1 != 2
true

julia> 1 == 1.0
true

julia> 1 < 2
true

julia> 1.0 > 3
false

julia> 1 >= 1.0
true

julia> -1 <= 1
true

julia> -1 <= -1
true

julia> -1 <= -2
false

julia> 3 < -0.5
false

整数は、ビットを比較する標準的な方法で比較されます。浮動小数点数は、IEEE 754 standardに従って比較されます。

  • 有限数は通常の順序で並びます。
  • 正のゼロと負のゼロは等しく、正のゼロが負のゼロより大きいわけではありません。
  • Infは自身と等しく、NaNを除くすべての値より大きくなります。
  • -Infは自身と等しく、NaNを除くすべての値より小さくなります。
  • NaNは、自身を含むどの値とも等しくなく、どの値よりも小さくも大きくもありません。

最後の点は意外に思われる可能性があるため、注意が必要です。

julia> NaN == NaN
false

julia> NaN != NaN
true

julia> NaN < NaN
false

julia> NaN > NaN
false

また、arraysを扱う際に問題を引き起こすことがあります。

julia> [1 NaN] == [1 NaN]
false

Juliaには、特殊な値かどうかを数値について判定する関数も用意されています。ハッシュキーの比較などに役立ちます。

関数判定内容
isequal(x, y)xとyが同一か
isfinite(x)xが有限数か
isinf(x)xが無限大か
isnan(x)xが数値でないか

isequalは、NaN同士を等しいとみなします。

julia> isequal(NaN, NaN)
true

julia> isequal([1 NaN], [1 NaN])
true

julia> isequal(NaN, NaN32)
true

isequalを使うと、符号付きゼロを区別することもできます。

julia> -0.0 == 0.0
true

julia> isequal(-0.0, 0.0)
false

符号付き整数、符号なし整数、浮動小数点数の間の比較は、扱いが難しい場合があります。Juliaでは、これらを正しく比較できるよう細心の注意が払われています。

その他の型では、isequalは既定で==を呼び出します。そのため、独自の型に対する等価性を定義するには、==メソッドを追加するだけで十分です。独自の等価性関数を定義する場合は、isequal(x,y)ならばhash(x) == hash(y)となることを保証するため、対応するhashメソッドも定義するとよいでしょう。

Chaining comparisons

多くの言語とは異なり、notable exception of Pythonでは比較を任意の長さで連鎖できます。

julia> 1 < 2 <= 2 < 3 == 3 > 2 >= 1 == 1 < 3 != 5
true

比較の連鎖は、数値計算のコードで便利なことがよくあります。連鎖比較では、スカラーの比較に&&演算子を使い、要素ごとの比較には&演算子を使うため、配列にも適用できます。たとえば、0 .< A .< 1は、Aの対応する要素が0から1の範囲にある箇所でtrueとなる、ブール配列を返します。

連鎖比較の評価動作に注意してください。

julia> v(x) = (println(x); x)
v (generic function with 1 method)

julia> v(1) < v(2) <= v(3)
2
1
3
true

julia> v(1) > v(2) <= v(3)
2
1
false

中央の式は一度だけ評価されます。v(1) < v(2) && v(2) <= v(3)と書いた場合のように、二度評価されることはありません。ただし、連鎖比較における評価順序は未定義です。表示などの副作用を伴う式を連鎖比較に使うことは、強く推奨されません。副作用が必要な場合は、短絡評価を行う&&演算子を明示的に使ってください（Short-Circuit Evaluationを参照）。

Elementary Functions

Juliaには、数学関数と演算子が幅広くそろっています。これらの数学演算は、意味のある定義が可能な限り広い数値クラスに対して定義されています。整数、浮動小数点数、有理数、複素数なども、定義が妥当な場合には対象となります。

さらに、これらの関数は（Juliaの他の関数と同様に）dot syntax f.(A)を使って、配列やその他のコレクションに「ベクトル化」して適用できます。たとえば、sin.(A)は、配列Aの各要素の正弦を計算します。

Operator Precedence and Associativity

Juliaでは、演算の優先順位と結合規則は、優先順位の高いものから順に次のようになります。

分類演算子結合規則
構文.の後に::左結合
べき乗^右結合
単項+ - ! ~ ¬ √ ∛ ∜ ⋆ ± ∓ <: >:右結合[1]
ビットシフト<< >> >>>左結合
分数//左結合
乗算* / % & \ ÷左結合[2]
加算+ - | ⊻左結合[2]
構文: ..左結合
構文|>左結合
構文<|右結合
比較> < >= <= == === != !== <:非結合
制御フロー&&の後に||、さらに?右結合
ペア=>右結合
代入= += -= *= /= //= \= ^= ÷= %= |= &= ⊻= <<= >>= >>>=右結合

Juliaのすべての演算子の優先順位については、このファイルの冒頭にある一覧を参照してください：src/julia-parser.scm。一覧にある演算子の中には、Baseモジュールでは定義されていないものもありますが、標準ライブラリ、パッケージ、またはユーザーコードで定義される場合があります。

組み込み関数Base.operator_precedenceを使うと、任意の演算子の数値としての優先順位も確認できます。数値が大きいほど優先順位が高くなります。

julia> Base.operator_precedence(:+), Base.operator_precedence(:*), Base.operator_precedence(:.)
(11, 12, 17)

julia> Base.operator_precedence(:sin), Base.operator_precedence(:+=), Base.operator_precedence(:(=))  # (Note the necessary parens on `:(=)`)
(0, 1, 1)

組み込み関数Base.operator_associativityを呼び出すと、演算子の結合規則を表すシンボルも取得できます。

julia> Base.operator_associativity(:-), Base.operator_associativity(:+), Base.operator_associativity(:^)
(:left, :none, :right)

julia> Base.operator_associativity(:⊗), Base.operator_associativity(:sin), Base.operator_associativity(:→)
(:left, :none, :right)

:sinのようなシンボルは、優先順位として0を返します。この値は、優先順位が最も低い演算子ではなく、無効な演算子を表します。同様に、このような演算子には:noneという結合規則が割り当てられます。

Numeric literal coefficients（たとえば2x）は、他の二項演算より優先順位の高い乗算として扱われます。ただし^の場合は例外で、指数として使われる場合に限って優先順位が高くなります。

julia> x = 3; 2x^2
18

julia> x = 3; 2^2x
64

隣接記法は単項演算子のように構文解析されます。指数との関係も同様に非対称で、-x^yと2x^yは、それぞれ-(x^y)と2(x^y)として解析されます。一方、x^-yとx^2yは、それぞれx^(-y)とx^(2y)として解析されます。

Numerical Conversions

Juliaでは、数値変換に3つの形式があり、精度を損なう変換の扱いがそれぞれ異なります。

  • T(x)またはconvert(T, x)という記法は、xを型Tの値に変換します。

    • Tが浮動小数点型の場合、結果は表現可能な最も近い値になります。正または負の無限大になることもあります。
    • Tが整数型の場合、xをTで表現できなければ、InexactErrorが発生します。

  • x % Tは、整数xを、xを2^nで割った余りと合同な整数型Tの値に変換します。ここでnは、Tのビット数です。つまり、二進表現を切り詰めて収まるようにします。

  • Rounding functionsでは、型Tを省略可能な引数として指定できます。たとえば、round(Int,x)はInt(round(x))の短縮形です。

次の例で、各形式の違いを示します。

julia> Int8(127)
127

julia> Int8(128)
ERROR: InexactError: trunc(Int8, 128)
Stacktrace:
[...]

julia> Int8(127.0)
127

julia> Int8(3.14)
ERROR: InexactError: Int8(3.14)
Stacktrace:
[...]

julia> Int8(128.0)
ERROR: InexactError: Int8(128.0)
Stacktrace:
[...]

julia> 127 % Int8
127

julia> 128 % Int8
-128

julia> round(Int8,127.4)
127

julia> round(Int8,127.6)
ERROR: InexactError: Int8(128.0)
Stacktrace:
[...]

独自の変換と型昇格を定義する方法については、Conversion and Promotionを参照してください。

Sign and absolute value functions

Trigonometric and hyperbolic functions

標準的な三角関数と双曲線関数もすべて定義されています。

sin    cos    tan    cot    sec    csc
sinh   cosh   tanh   coth   sech   csch
asin   acos   atan   acot   asec   acsc
asinh  acosh  atanh  acoth  asech  acsch
sinc   cosc

これらはすべて単一引数の関数です。ただしatanは、従来のatan2関数に対応する2つの引数も受け取ります。

また、sinpi(x)とcospi(x)を使うと、それぞれsin(pi * x)とcos(pi * x)をより高精度に計算できます。

ラジアンではなく度数法で三角関数を計算するには、関数名の末尾にdを付けます。たとえば、sind(x)は、xを度数法で指定したxの正弦を計算します。度数法に対応する三角関数の一覧は次のとおりです。

sind   cosd   tand   cotd   secd   cscd
asind  acosd  atand  acotd  asecd  acscd

Special functions

その他にも、多くの特殊数学関数がパッケージSpecialFunctions.jlで提供されています。

  • 1単項演算子+と-は、演算子++などとの曖昧さを避けるため、引数を明示的に括弧で囲む必要があります。その他の単項演算子の組み合わせは右結合として構文解析されます。たとえば、√√-aは√(√(-a))として解析されます。
  • 2演算子+、++、*は非結合です。a + b + cは+(a, b, c)として解析され、+(+(a, b), c)としては解析されません。ただし、+(a, b, c, d...)と*(a, b, c, d...)のフォールバックメソッドは、どちらも既定で左結合の評価を行います。
