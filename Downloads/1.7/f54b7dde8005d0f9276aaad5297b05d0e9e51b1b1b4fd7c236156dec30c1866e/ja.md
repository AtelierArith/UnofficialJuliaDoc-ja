```julia
struct Response
    proto   :: String
    url     :: String
    status  :: Int
    message :: String
    headers :: Vector{Pair{String,String}}
end
```

`Response`は、リクエストに対する成功レスポンスの情報をオブジェクトとして保持する型です。次のフィールドがあります。

  * `proto`: レスポンスの取得に使用したプロトコル
  * `url`: リダイレクトをたどった後、最終的にリクエストされたURL
  * `status`: 成功や失敗などを示すレスポンスのステータスコード
  * `message`: レスポンスの内容を説明するテキストメッセージ
  * `headers`: レスポンスに含まれていたヘッダー

これらのレスポンス情報の一部は、その意味や利用可否がリクエストに使用したプロトコルによって異なります。HTTP/SやS/FTPを含む多くのプロトコルでは、2xxのステータスコードは成功レスポンスを示します。ヘッダーをサポートしないプロトコルのレスポンスでは、ヘッダーのベクターは空になります。HTTP/2にはステータスメッセージがなく、ステータスコードのみが含まれるため、メッセージは空になります。
