```julia
spr!(uplo, α, x, AP)
```

`A` 行列を `A+α*x*x'` として更新します。ここで、`A` はパック形式 `AP` で与えられる対称行列、`x` はベクトルです。

`uplo = 'U'` の場合、配列 AP には対称行列の上三角部分を列ごとに順にパックして格納します。つまり、`AP[1]` には `A[1, 1]` が格納され、`AP[2]` と `AP[3]` にはそれぞれ `A[1, 2]` と `A[2, 2]` が格納され、以降も同様です。

`uplo = 'L'` の場合、配列 AP には対称行列の下三角部分を列ごとに順にパックして格納します。つまり、`AP[1]` には `A[1, 1]` が格納され、`AP[2]` と `AP[3]` にはそれぞれ `A[2, 1]` と `A[3, 1]` が格納され、以降も同様です。

スカラー入力 `α` は実数でなければなりません。

配列入力 `x` と `AP` は、すべて `Float32` 型または `Float64` 型でなければなりません。更新後の `AP` を返します。

!!! compat "Julia 1.8"
    `spr!` の使用には Julia 1.8 以降が必要です。
