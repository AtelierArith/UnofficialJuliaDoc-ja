```julia
hpmv!(uplo, α, AP, x, β, y)
```

`A` がパック形式 `AP` で与えられたエルミート行列の場合、ベクトル `y` を `α*A*x + β*y` として更新します。

`uplo = 'U'` の場合、配列 AP にはエルミート行列の上三角部分を列ごとに順にパックして格納します。つまり、`AP[1]` には `A[1, 1]` が、`AP[2]` と `AP[3]` にはそれぞれ `A[1, 2]` と `A[2, 2]` が格納され、以降も同様です。

`uplo = 'L'` の場合、配列 AP にはエルミート行列の下三角部分を列ごとに順にパックして格納します。つまり、`AP[1]` には `A[1, 1]` が、`AP[2]` と `AP[3]` にはそれぞれ `A[2, 1]` と `A[3, 1]` が格納され、以降も同様です。

スカラー入力 `α` と `β` は、複素数または実数でなければなりません。

配列入力 `x`、`y`、`AP` は、すべて `ComplexF32` 型または `ComplexF64` 型でなければなりません。

更新後の `y` を返します。

!!! compat "Julia 1.5"
    `hpmv!` は Julia 1.5 以降で利用できます。
